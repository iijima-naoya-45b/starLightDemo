## 📝 Claudeでポートフォリオ・技術ブログを効率的に作成する

### 🎯 ポートフォリオ作成の「3つのステップ」

#### ステップ1: プロジェクトの棚卸し

```
「私のこれまでのプロジェクトを、ポートフォリオ向けに整理してください：

【プロジェクト一覧】
1. [プロジェクト名]: [簡単な説明]
2. [プロジェクト名]: [簡単な説明]
...

各プロジェクトについて：
- アピールポイント
- 使用技術
- 実装した機能
- 成果（数値で）
- 改善案

転職活動で効果的にアピールできる形に整理してください。」
```

#### ステップ2: ポートフォリオサイト設計

```
「エンジニアのポートフォリオサイトを設計してください：

【必要なセクション】
- 自己紹介
- スキルセット
- プロジェクト一覧
- ブログ記事
- 連絡先

各セクションの内容案と、印象的な見せ方を提案してください。」
```

#### ステップ3: 実装と公開

```
「Next.js + TailwindCSSで、ポートフォリオサイトを実装したいです：

段階的に：
1. 基本レイアウト（1日）
2. プロジェクト表示（2日）
3. ブログ機能（2日）
4. デプロイ（Vercel）

実装手順とコード例を教えてください。」
```

**ポケモン版**: **「図鑑を完成させる」**——実績を可視化。

### 2. ✍️ 技術ブログ執筆の「5つのテンプレート」

#### テンプレート1: 「学習記録」

```
「以下の学習内容を、技術ブログ記事にしてください：

【学んだこと】
- [技術名]
- [学習期間]
- [つまずいたポイント]
- [解決方法]

【記事構成】
1. なぜこの技術を学んだか
2. 学習の流れ
3. つまずいたポイントと解決策
4. 実際に作ったもの
5. 学びと次のステップ

初心者にも読みやすく、3000文字程度で。」
```

#### テンプレート2: 「問題解決記録」

```
「以下のバグ解決プロセスを、ブログ記事にしてください：

【問題】
[どんなバグだったか]

【解決までの道のり】
[試したこと、最終的な解決策]

【記事構成】
1. 遭遇した問題
2. 原因調査のプロセス
3. 試行錯誤
4. 解決策
5. 学び・予防策

同じ問題で困っている人の役に立つ内容で。」
```

#### テンプレート3: 「技術比較」

```
「[技術A] vs [技術B]の比較記事を書いてください：

【比較項目】
- 学習コスト
- パフォーマンス
- エコシステム
- 適したユースケース

【記事構成】
1. なぜこの比較が重要か
2. 各技術の概要
3. 項目別比較
4. 実際に使ってみた感想
5. 結論・推奨

実体験を交えて、2500文字程度で。」
```

**ポケモン版**: **「冒険記を執筆」**——経験を記録し共有。
