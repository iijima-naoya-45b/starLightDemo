## 💼 Claude で面接・転職活動を成功させる戦略

### 🎯 転職活動の「5つのフェーズ」

#### フェーズ1: 自己分析と目標設定

```
「転職活動の自己分析を手伝ってください：

【現状】
- 現在の職種: [職種]
- 経験年数: [年数]
- 主なスキル: [スキル一覧]
- 実績: [実績]

【目標】
- なりたい姿: [理想]
- 希望年収: [金額]
- 希望環境: [環境]

【質問】
1. 私の強みは何ですか？
2. 市場価値はどの程度ですか？
3. どんな企業・ポジションが合いますか？
4. スキルギャップは何ですか？

客観的に分析してください。」
```

#### フェーズ2: 職務経歴書の作成

```
「以下の経歴を、魅力的な職務経歴書にしてください：

【経歴】
[箇条書きの経歴]

【アピールポイント】
- 技術スキル
- 成果（数値で）
- 問題解決力
- チーム貢献

採用担当者が「会いたい」と思う内容に仕上げてください。」
```

#### フェーズ3: 技術面接の準備

```
「[ポジション]の技術面接で聞かれる質問を30個作成してください：

【レベル別】
- 基礎（10問）
- 実践（10問）
- 応用（10問）

各質問に：
- 模範回答
- 補足説明
- アピールポイント

を含めてください。」
```

**ポケモン版**: **「四天王戦の準備」**——万全の態勢で挑む。

### 2. 🔥 面接対策の「7つのシナリオ」

#### シナリオ1: 自己紹介

```
「1分間の自己紹介を作成してください：

【含めるべき要素】
- 経歴の概要
- 主な技術スキル
- 代表的な実績
- 志望動機の導入

印象に残り、次の質問につながる内容で。」
```

#### シナリオ2: 技術的な質問

```
「[技術トピック]について、面接で説明する練習をしたいです：

【説明のポイント】
- 初心者にもわかるように
- 具体例を交えて
- 実務での経験も含めて

3分で説明できる内容を作成してください。」
```

#### シナリオ3: プロジェクト説明

```
「私のプロジェクトを、面接で魅力的に説明したいです：

【プロジェクト】
[プロジェクト概要]

【説明に含めるべき要素】
- 課題と背景
- 自分の役割
- 技術的な工夫
- 成果（数値で）
- 学び

STAR法（Situation, Task, Action, Result）で整理してください。」
```

#### シナリオ4: 「なぜ転職？」

```
「「なぜ転職を考えているのですか？」への回答を作成してください：

【現状】
[現在の不満や課題]

【ポジティブな回答】
- 成長意欲を示す
- 新しい挑戦への意欲
- ネガティブにならない

を意識して、30秒〜1分で話せる内容で。」
```

#### シナリオ5: 逆質問

```
「面接の最後に聞くべき、印象的な逆質問を10個提案してください：

【カテゴリ】
- 技術スタック・開発環境
- チーム文化・働き方
- 成長機会・キャリアパス
- 事業・プロダクト

意欲と関心が伝わる質問で。」
```

**ポケモン版**: **「戦略を完璧に」**——あらゆるパターンに対応。

### 3. 📊 模擬面接の実践

```
「模擬面接を実施してください：

【設定】
- ポジション: [職種]
- レベル: [シニア/ミドル/ジュニア]
- 面接時間: 30分想定

【進め方】
1. 質問を1つずつ出してください
2. 私が回答します
3. フィードバックをください
4. 次の質問に進む

最初の質問から始めてください。」
```

**効果**: 実戦形式で練習できる

**ポケモン版**: **「ジムリーダーと模擬戦」**——本番前の練習。

### 4. 🎓 まとめ

**転職活動の5フェーズ**:
1. 自己分析
2. 職務経歴書作成
3. 技術面接準備
4. 模擬面接
5. 継続的な改善

**面接対策の7シナリオ**:
1. 自己紹介
2. 技術質問
3. プロジェクト説明
4. 転職理由
5. 逆質問
6. コーディング試験
7. システム設計

**最後に**:
Claudeを使えば、面接準備も効率的——万全の準備で、理想の転職を実現しましょう！
