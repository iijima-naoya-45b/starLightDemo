## 💼 実務で即使えるClaude活用パターン総集編

### 🎯 場面別：即使えるプロンプト集

#### 場面1: 緊急バグ対応

```
「本番環境で以下のエラーが発生しています。緊急対応が必要です：

【エラー情報】
- エラーメッセージ: [全文]
- 発生頻度: [回数/時間]
- 影響範囲: [ユーザー数]
- ログ: [関連ログ]

【緊急度】高

【求める対応】
1. 即座に考えられる原因（優先度順）
2. 暫定対策（5分以内に実施可能）
3. 根本対策（後日実施）
4. 再発防止策

緊急度を理解して、迅速に回答してください。」
```

#### 場面2: 技術的意思決定

```
「以下の技術選定について、明日までに決定が必要です：

【選択肢】
- A: [技術A]
- B: [技術B]
- C: [技術C]

【判断基準】
- パフォーマンス（重要度: 高）
- 学習コスト（重要度: 中）
- コミュニティ（重要度: 中）

【制約】
- 予算: [金額]
- 期限: [日数]
- チーム: [人数・スキル]

客観的なデータと、明確な推奨案を提示してください。」
```

#### 場面3: システム設計レビュー

```
「以下のシステム設計をレビューしてください：

【設計概要】
[アーキテクチャ図またはテキスト説明]

【レビュー観点】
- スケーラビリティ
- 可用性
- セキュリティ
- コスト効率
- 保守性

潜在的な問題点を指摘し、改善案を提示してください。」
```

**ポケモン版**: **「状況に応じた最適な技」**——場面別の必殺技。

### 2. 🔥 チーム開発での実戦パターン

#### パターン1: コードレビューの効率化

```
「PRレビュー依頼が10件溜まっています。効率的にレビューしたいです：

【依頼】
各PRについて：
1. 変更概要の要約（3行）
2. 重大な問題の有無（Yes/No）
3. レビュー優先度（高/中/低）
4. 推定レビュー時間（分）

優先順位をつけて、レビュー計画を立てたいです。

[PR一覧]
」
```

#### パターン2: ドキュメント自動生成

```
「スプリントで実装した機能のドキュメントを一括作成したいです：

【実装した機能】
[機能一覧]

【必要なドキュメント】
1. ユーザー向け: 使い方ガイド
2. 開発者向け: 技術仕様書
3. QA向け: テスト仕様書
4. 運用向け: 運用手順書

各ドキュメントのドラフトを作成してください。」
```

#### パターン3: ミーティング議事録

```
「以下のミーティングメモを、議事録として整形してください：

[雑多なメモ]

【整形形式】
- 日時・参加者
- 議題
- 決定事項（優先度付き）
- アクションアイテム（担当者・期限）
- 懸念事項
- 次回ミーティング

読み返してすぐわかる形式で。」
```

**ポケモン版**: **「チーム戦の戦略」**——連携して勝つ。

### 3. 📊 運用・保守での実戦パターン

#### パターン1: ログ分析

```
「以下のエラーログを分析してください：

[大量のログ]

【分析内容】
1. エラーの種類別集計
2. 頻出エラーTop 5
3. エラーの傾向（時間帯、パターン）
4. 優先的に対応すべきエラー
5. 各エラーの対処法

実用的な分析レポートにしてください。」
```

#### パターン2: パフォーマンス改善

```
「アプリケーションが遅いという報告が増えています：

【現状】
- 応答時間: [秒]
- リクエスト数: [回/秒]
- リソース使用率: [%]

【目標】
- 応答時間: 1秒以内
- スケーラビリティ: 10倍対応

【求める内容】
1. ボトルネック予測（上位5つ）
2. 改善策（即効性順）
3. 実装難易度と効果の見積もり
4. 優先順位付きの改善計画

データに基づいた提案をお願いします。」
```

#### パターン3: インシデント対応

```
「本番障害が発生しました。ポストモーテムを作成してください：

【インシデント情報】
- 発生日時: [日時]
- 影響: [内容]
- 原因: [判明した原因]
- 対応: [実施した対応]

【ポストモーテム構成】
1. インシデント概要
2. タイムライン
3. 根本原因分析
4. 対応の評価
5. 再発防止策
6. 学び

チーム全体で共有できる形式で。」
```

**ポケモン版**: **「長期戦の戦略」**——持続可能な運用。

### 4. 🎓 まとめ：実戦パターンの心得

**3つの場面**:
1. 緊急対応 - 迅速な判断
2. チーム開発 - 効率的な協働
3. 運用保守 - 安定稼働

**実戦での心得**:
- コンテキストを明確に
- 優先度を意識
- 実用性を重視
- チームで共有

**最後に**:
実務では「速さ」と「正確さ」が求められます——これらのパターンを使って、即座に価値を出しましょう！

**ポケモン版**: **「実戦で勝つ技術」**——理論より実践！
