## 🎯 プロンプトエンジニアリング基礎：Claude と正しく対話する技術

### 📝 プロンプトエンジニアリングの定義

**ポケモンで例えると**: プロンプトエンジニアリングは、**「ポケモンに的確な指示を出す技術」**です。同じポケモンでも、指示が曖昧なら技は外れる——Claudeも、**「適切な質問をすれば、期待通りの回答が返ってくる」**のです。

プロンプトエンジニアリングは、AIに最適な指示を与える技術——単なる質問ではなく、**「戦略的なコミュニケーション」**です。この技術を習得すれば、Claudeの能力を最大限に引き出せます。

この記事は、**「プロンプトエンジニアリングの基礎から実践まで」**の完全ガイドです。

### 1. 🎯 プロンプトの「3大要素」

良いプロンプトには、3つの必須要素があります。

| 要素 | 説明 | 悪い例 | 良い例 |
|------|------|--------|--------|
| **明確性** | 何をして欲しいか明確 | 「コードを直して」 | 「このReactコンポーネントで、ボタンクリック時に状態が更新されない問題を修正してください」 |
| **コンテキスト** | 背景情報を提供 | 「エラーが出る」 | 「Next.js 14のApp Routerで、以下のエラーが出ます：[エラー全文]」 |
| **制約条件** | 制限や要件を指定 | 「APIを作って」 | 「TypeScriptとPrismaを使って、ユーザー認証APIを作成してください。JWTトークンを使用し、リフレッシュトークンにも対応してください」 |

**ポケモン版**: **「技を正確に指示」**——どの技を、誰に、どのタイミングで。

### 2. 🚀 基礎テクニック1: 5W1Hで構造化する

#### 2-1. What（何を）

**やりたいことを明確に**:
- ❌ 「機能を作って」
- ✅ 「ユーザーがログインできる機能を作成してください」

#### 2-2. Why（なぜ）

**目的を伝える**:
- ❌ 「最適化して」
- ✅ 「ページの読み込みが3秒かかっていて、ユーザーが離脱してしまうので、1秒以内に短縮したいです」

**効果**: Claudeが目的に沿った提案をできる

#### 2-3. Who（誰が）

**対象ユーザーを明確に**:
- ❌ 「使いやすいUIにして」
- ✅ 「初心者ユーザー向けに、直感的でわかりやすいUIを設計してください」

#### 2-4. When（いつ）

**タイミングや条件を指定**:
- ❌ 「通知を送って」
- ✅ 「ユーザーが新規登録したときに、ウェルカムメールを即座に送信してください」

#### 2-5. Where（どこで）

**場所や環境を指定**:
- ❌ 「動かない」
- ✅ 「本番環境（Vercel）では動作しますが、ローカル環境では以下のエラーが出ます」

#### 2-6. How（どのように）

**方法や手段を指定**:
- ❌ 「データを保存して」
- ✅ 「Prismaを使ってPostgreSQLにデータを保存し、トランザクションで整合性を保証してください」

**ポケモン版**: **「5W1Hで戦略を立てる」**——状況を正確に伝える。

### 3. 🔥 基礎テクニック2: ロールを設定する

#### パターン1: 専門家ロール

```
「あなたはReactのシニアエンジニアです。
以下のコンポーネントのパフォーマンス問題を診断してください：

[コード]

特に以下の観点から分析してください：
- 不要なre-render
- メモ化の機会
- useEffectの依存配列
- 計算コストの高い処理」
```

**効果**: 専門的な視点からの回答

#### パターン2: レビュアーロール

```
「あなたは厳格なコードレビュアーです。
以下のプルリクエストをレビューしてください：

[差分]

以下の基準で評価してください：
- セキュリティ（脆弱性の有無）
- パフォーマンス（ボトルネックの有無）
- 可読性（理解しやすさ）
- 保守性（将来の変更のしやすさ）

各項目について、5段階評価と具体的な改善提案をしてください。」
```

**効果**: 批判的な視点からの分析

#### パターン3: メンターロール

```
「あなたは優しいメンターです。
プログラミング初心者の私に、ReactのuseEffectの使い方を教えてください。

以下の点を含めて、わかりやすく説明してください：
- useEffectとは何か（初心者向けの比喩で）
- いつ使うのか（具体的なシーン）
- 使い方の例（シンプルなコード例）
- よくある間違い（初心者が陥りやすいミス）
- 覚えておくべきポイント（3つまで）」
```

**効果**: 初心者にもわかりやすい説明

**ポケモン版**: **「トレーナーのタイプを指定」**——状況に応じて最適な相手と戦う。

### 5. 📊 基礎テクニック4: 例を示す（Few-Shot Learning）

#### パターン1: 入力例 + 期待する出力例

```
「以下の例に従って、関数のドキュメントを生成してください：

【例】
入力：
function add(a: number, b: number): number {
  return a + b;
}

出力：
/**
 * 2つの数値を加算します
 * @param a - 1つ目の数値
 * @param b - 2つ目の数値
 * @returns 加算結果
 * @example
 * add(1, 2) // => 3
 */

では、以下の関数にドキュメントを追加してください：

[対象の関数]」
```

#### パターン2: 複数の例を示す

```
「以下の例のように、関数名から説明を生成してください：

例1：
getUserById → 「IDを指定してユーザー情報を取得する」

例2：
createNewPost → 「新しい投稿を作成する」

例3：
deleteCommentById → 「IDを指定してコメントを削除する」

では、以下の関数名の説明を生成してください：
- updateUserProfile
- fetchProductList
- validateEmailAddress」
```

**効果**: Claudeが期待する形式を正確に理解

**ポケモン版**: **「技の使い方を実演」**——見せれば理解が速い。

### 6. 🎯 基礎テクニック5: 制約条件を明示する

#### パターン1: 技術的制約

```
「以下の制約の下で、ログイン機能を実装してください：

【技術的制約】
- Next.js 14 App Router必須
- Server Componentsを優先
- Client Componentsは最小限
- TypeScript strict mode
- Prisma + PostgreSQL

【機能要件】
- メール・パスワード認証
- セッション管理
- CSRF対策

【非機能要件】
- パフォーマンス: 初回表示1秒以内
- セキュリティ: OWASP Top 10対応
- 保守性: コメント充実」
```

#### パターン2: ビジネス制約

```
「以下のビジネス要件を満たす実装を提案してください：

【ビジネス制約】
- 予算: サーバーコスト月1万円以内
- スケール: 月間10万PV想定
- 納期: 2週間で MVP完成
- チーム: 開発者1名（私だけ）

【優先順位】
1. 速く動くものを作る（完璧を求めない）
2. コストを抑える
3. スケーラブルな設計（将来の拡張を考慮）」
```

#### パターン3: 学習コスト制約

```
「私はReact初心者です。以下の条件で実装方法を教えてください：

【私のスキルレベル】
- JavaScript: 中級
- React: 初心者（Hooks少し知ってる）
- TypeScript: 未経験

【学習制約】
- 新しいライブラリは最小限に
- 複雑なパターンは避ける
- コメントで詳しく説明

【期待】
- 初心者でも理解できる説明
- なぜそうするのかの理由
- よくある間違いの指摘」
```

**ポケモン版**: **「パーティの制約を伝える」**——使えるポケモンを明確に。

### 7. 🚨 よくある5つの失敗

#### 失敗1: 曖昧な質問

❌ 「このコードを良くして」

✅ 「このコードのパフォーマンスを改善してください。特に、ループ処理とデータベースクエリの最適化を重視してください。」

#### 失敗2: コンテキスト不足

❌ 「エラーが出ます」

✅ 「Next.js 14で、以下のエラーが出ます：[エラー全文]。環境: Node 20.x、やろうとしていたこと: [説明]」

#### 失敗3: 一度に詰め込みすぎ

❌ 「ログイン機能とダッシュボードとAPIと管理画面を全部作って」

✅ 「まずログイン機能を作成してください。完成したら、次にダッシュボードに進みます。」

#### 失敗4: 期待値が不明確

❌ 「説明して」

✅ 「初心者向けに、比喩を使ってわかりやすく説明してください。専門用語は避けるか、使う場合は注釈をつけてください。」

#### 失敗5: フィードバックなし

❌ 回答が不十分でも「ありがとう」で終わり

✅ 「この説明だと〇〇の部分がまだわかりません。もう少し詳しく教えてください。」

**ポケモン版**: **「指示が曖昧で技が外れる」**——明確な指示が成功の鍵。
