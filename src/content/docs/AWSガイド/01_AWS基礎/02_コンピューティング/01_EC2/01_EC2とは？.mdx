## Amazon EC2 (Elastic Compute Cloud) とは？

Amazon EC2は、AWSクラウド上で仮想サーバー（インスタンス）を起動できるコンピューティングサービスです。

### 基本概念

#### EC2の特徴

```yaml
主要機能:
  - 仮想サーバーの起動・停止
  - 柔軟なスケーリング
  - 従量課金制
  - 豊富なインスタンスタイプ
  - カスタマイズ可能な環境

メリット:
  - 初期投資不要
  - 数分で起動
  - 必要に応じて増減
  - グローバル展開容易
```

### インスタンスタイプ

#### 1. 汎用（General Purpose）

```yaml
T3/T3a/T4g:
  用途: Webサーバー、開発環境
  特徴: バースト可能、コスト効率
  CPU: 2〜8 vCPU
  メモリ: 0.5〜32 GB
  価格: $0.0104/時間〜

M6i/M6a/M7g:
  用途: アプリケーションサーバー
  特徴: バランス型
  CPU: 2〜128 vCPU
  メモリ: 8〜512 GB
  価格: $0.096/時間〜
```

#### 2. コンピューティング最適化（Compute Optimized）

```yaml
C6i/C6a/C7g:
  用途: HPC、バッチ処理、ゲームサーバー
  特徴: 高性能CPU
  CPU: 2〜128 vCPU
  メモリ: 4〜256 GB
  価格: $0.085/時間〜
```

#### 3. メモリ最適化（Memory Optimized）

```yaml
R6i/R6a/R7g:
  用途: データベース、キャッシュ、インメモリ処理
  特徴: 大容量メモリ
  CPU: 2〜128 vCPU
  メモリ: 16〜1024 GB
  価格: $0.126/時間〜

X2iedn:
  用途: SAP HANA、大規模DB
  特徴: 超大容量メモリ
  メモリ: 最大4TB
```

#### 4. ストレージ最適化（Storage Optimized）

```yaml
I4i:
  用途: NoSQL DB、データウェアハウス
  特徴: 高速SSD
  ストレージ: NVMe SSD

D3:
  用途: 分散ファイルシステム
  特徴: 大容量HDD
  ストレージ: HDD
```

#### 5. 高速コンピューティング（Accelerated Computing）

```yaml
P4/P5:
  用途: 機械学習、深層学習
  特徴: GPU搭載（NVIDIA）
  GPU: 8〜16個

G5:
  用途: グラフィックス、ゲームストリーミング
  特徴: GPU搭載（NVIDIA A10G）
```

### 購入オプション

#### 1. オンデマンドインスタンス

```yaml
特徴:
  - 時間単位課金
  - 最小1分から
  - コミットメント不要

適用:
  - 短期ワークロード
  - 予測不可能な負荷
  - 開発・テスト

価格例:
  t3.medium: $0.0416/時間
  m6i.large: $0.096/時間
```

#### 2. リザーブドインスタンス

```yaml
特徴:
  - 1年/3年コミット
  - 最大72%割引
  - 支払いオプション: 全額前払い、一部前払い、前払いなし

適用:
  - 長期安定ワークロード
  - 予測可能な利用

価格例（3年全額前払い）:
  t3.medium: 最大54%割引
  m6i.large: 最大72%割引
```

#### 3. スポットインスタンス

```yaml
特徴:
  - 最大90%割引
  - AWS余剰キャパシティ利用
  - 中断の可能性あり

適用:
  - バッチ処理
  - データ分析
  - CI/CD
  - ステートレスアプリ

価格例:
  t3.medium: $0.0125/時間（70%割引）
  m6i.large: $0.0288/時間（70%割引）
```

#### 4. Savings Plans

```yaml
特徴:
  - 1年/3年コミット
  - 最大72%割引
  - インスタンスタイプ変更可能
  - リージョン変更可能

タイプ:
  Compute Savings Plans:
    - EC2, Lambda, Fargate対象
    - 柔軟性高
  
  EC2 Instance Savings Plans:
    - EC2のみ対象
    - 割引率高
```

### ストレージ

#### 1. EBS（Elastic Block Store）

```yaml
gp3（汎用SSD - 推奨）:
  用途: ほとんどのワークロード
  IOPS: 3,000〜16,000
  スループット: 125〜1,000 MB/s
  価格: $0.08/GB/月

gp2（汎用SSD - 旧世代）:
  用途: 汎用
  IOPS: 100〜16,000（サイズ連動）
  価格: $0.10/GB/月

io2（プロビジョンドIOPS SSD）:
  用途: データベース、高IOPS要求
  IOPS: 最大64,000
  価格: $0.125/GB/月 + IOPS料金

st1（スループット最適化HDD）:
  用途: ビッグデータ、ログ処理
  スループット: 最大500 MB/s
  価格: $0.045/GB/月
```

#### 2. インスタンスストア

```yaml
特徴:
  - 物理的に接続されたストレージ
  - 高速（NVMe SSD）
  - 一時的（インスタンス停止で消失）
  - 追加料金なし

適用:
  - キャッシュ
  - バッファ
  - スクラッチデータ
```

### ネットワーク

#### ENI（Elastic Network Interface）

```yaml
特徴:
  - 仮想ネットワークカード
  - インスタンスにアタッチ
  - プライベートIP、パブリックIP
  - セキュリティグループ適用

用途:
  - 複数IPアドレス
  - 管理用ネットワーク分離
  - フェイルオーバー
```

#### 拡張ネットワーキング

```yaml
ENA（Elastic Network Adapter）:
  - 最大100 Gbps
  - 低レイテンシー
  - 高PPS（packets per second）
  - ほとんどのインスタンスタイプでサポート

EFA（Elastic Fabric Adapter）:
  - HPC向け
  - OS-bypass
  - 超低レイテンシー
```

### セキュリティ

#### セキュリティグループ

```yaml
特徴:
  - ステートフルファイアウォール
  - インスタンスレベル
  - 許可ルールのみ

例:
  インバウンド:
    - SSH (22): 管理者IP
    - HTTP (80): 0.0.0.0/0
    - HTTPS (443): 0.0.0.0/0
  
  アウトバウンド:
    - デフォルト全許可
```

#### キーペア

```yaml
SSH接続:
  - 公開鍵・秘密鍵ペア
  - 起動時に指定
  - .pem形式

RDP接続:
  - Windowsインスタンス
  - キーペアで管理者パスワード復号化
```

### Auto Scaling

```yaml
Auto Scaling Group:
  最小: 2
  最大: 10
  希望: 3

スケーリングポリシー:
  ターゲット追跡:
    - CPU使用率70%維持
  
  ステップスケーリング:
    - CPU 80%以上: +2インスタンス
    - CPU 60%以下: -1インスタンス
  
  スケジュール:
    - 平日9-18時: 5インスタンス
    - それ以外: 2インスタンス
```

### まとめ

**EC2の重要ポイント:**

- **インスタンスタイプ選択**: ワークロードに応じた適切な選択
- **購入オプション**: コスト最適化（RI、Spot、Savings Plans）
- **ストレージ**: EBSタイプ選択、インスタンスストア理解
- **Auto Scaling**: 可用性とコスト最適化
- **セキュリティ**: セキュリティグループ、キーペア管理

EC2は、AWSの最も基本的で重要なコンピューティングサービスです。
