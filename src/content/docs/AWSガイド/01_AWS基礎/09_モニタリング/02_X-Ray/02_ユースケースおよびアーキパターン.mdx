## ユースケース

```yaml
マイクロサービス:
  - サービス間依存関係可視化
  - レイテンシ分析
  - エラー追跡

Lambda:
  - 関数間呼び出し追跡
  - Cold Start分析
  - DynamoDB統合
```

## アーキテクチャパターン

```yaml
構成:
  - Lambda: 環境変数で有効化
  - API Gateway: ステージ設定
  - ALB: リスナールール
  - X-Ray Daemon: EC2/ECS
```

## まとめ

**設計ポイント:**
- サービスマップ活用
- サンプリング設定
- アノテーション追加
