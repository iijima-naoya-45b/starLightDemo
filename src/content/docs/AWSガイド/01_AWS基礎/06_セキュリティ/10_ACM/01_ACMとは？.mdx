## AWS ACM (Certificate Manager) とは？

ACMは、SSL/TLS証明書のプロビジョニング、管理、デプロイを容易にする、フルマネージドサービスです。

### 主要機能

#### 1. SSL/TLS証明書の管理

```yaml
概要:
  - パブリック証明書の無料発行
  - 自動更新
  - AWSサービスとの統合
  - 証明書のライフサイクル管理

対応証明書:
  パブリック証明書:
    - ACMが発行
    - ドメイン検証（DV）証明書
    - 無料
    - 自動更新
  
  プライベート証明書:
    - AWS Private CA必要
    - 内部アプリケーション用
    - 有料
    - カスタムCA階層

  インポート証明書:
    - サードパーティCA発行
    - 既存証明書の移行
    - 無料（管理のみ）
    - 手動更新
```

#### 2. ドメイン検証方法

```yaml
DNS検証:
  - 推奨方法
  - CNAMEレコード追加
  - 自動更新対応
  - ワイルドカード証明書対応
  - Route 53で自動化可能

メール検証:
  - WHOISメール送信
  - ドメイン管理者承認
  - 手動プロセス
  - 更新時に再検証必要
  - レガシー方法

選択基準:
  DNS検証（推奨）:
    ✅ 自動化可能
    ✅ Route 53統合
    ✅ ワイルドカード対応
    ✅ 自動更新
  
  メール検証:
    ❌ 手動承認必要
    ❌ メール受信必須
    ❌ 自動化困難
    ⚠️  従来の方法
```

### 証明書の種類

#### パブリック証明書

```yaml
特徴:
  - ACMが発行
  - 無料
  - 自動更新
  - 90日毎に自動更新
  - ドメイン検証（DV）のみ

サポート範囲:
  単一ドメイン:
    - example.com
  
  サブドメイン:
    - www.example.com
    - api.example.com
  
  ワイルドカード:
    - *.example.com
    - すべてのサブドメイン対応
  
  複数ドメイン:
    - SAN（Subject Alternative Name）
    - 最大10ドメイン
    - 追加ドメイン設定可能

対応リージョン:
  - 全商用リージョン
  - CloudFrontはus-east-1のみ
  - リージョナルサービスは同一リージョン
```

#### プライベート証明書

```yaml
用途:
  - 内部アプリケーション
  - マイクロサービス間通信
  - IoTデバイス
  - 企業内ネットワーク

要件:
  - AWS Private CA必要
  - CA階層設定
  - 有料サービス

料金:
  Private CA:
    - $400/月（CA稼働時間）
  
  証明書発行:
    - $0.75/証明書/月
  
  使用例:
    CA 1台 + 証明書10枚:
    $400 + ($0.75 × 10) = $407.50/月
```

### 統合サービス

```yaml
Elastic Load Balancing:
  ALB:
    - HTTPS リスナー
    - SNI対応
    - 複数証明書
  
  NLB:
    - TLS リスナー
    - TLS Termination
  
  CLB:
    - HTTPS/SSL リスナー
    - レガシー

CloudFront:
  - カスタムドメイン
  - SNI または専用IP
  - us-east-1 のACM証明書必須
  - 複数オリジン対応

API Gateway:
  - カスタムドメイン
  - REST API
  - HTTP API
  - WebSocket API
  - リージョナルまたはエッジ最適化

Elastic Beanstalk:
  - 環境のHTTPS設定
  - ロードバランサー統合

その他:
  - App Runner
  - Amazon Cognito
  - AWS Nitro Enclaves
  - CloudFormation
```

### 証明書のライフサイクル

```yaml
発行プロセス:
  1. 証明書リクエスト:
     - ドメイン名指定
     - 検証方法選択
     - タグ付け
  
  2. ドメイン検証:
     DNS検証:
       - CNAMEレコード追加
       - Route 53で自動化可能
     
     メール検証:
       - 管理者メール確認
       - リンククリック承認
  
  3. 発行完了:
     - 通常数分～数時間
     - 検証完了後に発行
     - AWSサービスで利用可能

自動更新:
  条件:
    - ACM発行の証明書
    - DNS検証
    - DNSレコード維持
  
  プロセス:
    - 期限60日前に開始
    - 自動的にDNS検証
    - 新証明書にローテーション
    - ダウンタイムなし
  
  注意点:
    - メール検証は自動更新不可
    - インポート証明書は手動更新
    - DNS検証レコード削除厳禁

期限切れ対策:
  - EventBridgeで通知
  - CloudWatch Metricsで監視
  - 期限前にアラート
```

### セキュリティ機能

```yaml
秘密鍵管理:
  - ACMが安全に保管
  - HSM（Hardware Security Module）使用
  - 秘密鍵エクスポート不可
  - FIPS 140-2 Level 2準拠

暗号化スイート:
  - TLS 1.0, 1.1, 1.2, 1.3
  - モダンな暗号化アルゴリズム
  - サービスごとに設定可能
  - セキュリティポリシー選択

アクセス制御:
  - IAMポリシー
  - タグベースアクセス制御
  - リソースベース権限
  - 最小権限の原則

監査:
  - CloudTrail統合
  - 全API呼び出し記録
  - 証明書発行・削除ログ
  - コンプライアンス対応
```

### リージョン制約

```yaml
重要な制約:
  CloudFront:
    - us-east-1 のACM証明書のみ
    - グローバルサービス
    - リージョン間複製不可
  
  リージョナルサービス（ALB, API Gateway等）:
    - 同一リージョンのACM証明書
    - リージョンごとに証明書発行必要
    - マルチリージョン構成は複数証明書

戦略:
  CloudFront使用:
    - us-east-1に証明書発行
  
  ALB/API Gateway（マルチリージョン）:
    - 各リージョンに同じドメインの証明書発行
    - DNS検証は同じCNAME使用可能
    - Route 53でルーティング
```

### モニタリング

```yaml
CloudWatch Metrics:
  DaysToExpiry:
    - 証明書の残り日数
    - 期限切れアラート設定
    - インポート証明書対象

EventBridge:
  イベント:
    - 証明書期限切れ接近
    - 証明書発行
    - 証明書削除
    - 検証失敗
  
  通知例:
    - SNS経由でメール通知
    - Lambda関数トリガー
    - 自動対応フロー

CloudTrail:
  記録内容:
    - RequestCertificate
    - DeleteCertificate
    - ImportCertificate
    - AddTagsToCertificate
    - DescribeCertificate
```

### 料金

#### パブリック証明書

| 項目 | 価格 | 備考 |
|---|---|---|
| **ACM発行証明書** | 無料 | パブリック証明書 |
| **自動更新** | 無料 | DNS検証の場合 |
| **証明書管理** | 無料 | 発行・削除・更新 |

#### プライベート証明書

| 項目 | 価格 | 備考 |
|---|---|---|
| **Private CA** | $400/月 | CA稼働時間課金 |
| **証明書発行** | $0.75/証明書/月 | 発行された証明書数 |

#### インポート証明書

| 項目 | 価格 | 備考 |
|---|---|---|
| **証明書管理** | 無料 | ACMでの管理のみ |
| **購入費用** | 別途 | サードパーティCAで購入 |

**無料枠の特徴:**
- パブリック証明書は完全無料
- 発行数の制限なし
- 自動更新も無料
- AWSサービス統合無料

**料金計算例（プライベート証明書）:**

| 項目 | 計算 | 料金 |
|---|---|---|
| Private CA 1台 | $400.00 | $400.00 |
| 証明書 50枚 | 50 × $0.75 | $37.50 |
| **合計** | - | **$437.50/月** |

**コスト削減のヒント:**
- パブリック証明書は無料活用
- Private CAは必要最小限
- 証明書の統合（ワイルドカード活用）
- 不要な証明書の削除

### 制限事項

```yaml
リクエスト制限:
  - 証明書数: リージョンごと 2,500
  - リクエストレート: アカウントごと制限あり
  - 上限緩和申請可能

ドメイン制限:
  - SAN: 最大10ドメイン
  - 追加ドメイン: 最大100（申請必要）
  - ワイルドカード: *.example.com形式のみ

証明書タイプ:
  - DV証明書のみ（パブリック）
  - OV/EV証明書非対応
  - コード署名証明書非対応

秘密鍵:
  - エクスポート不可（セキュリティ理由）
  - EC2等では使用不可
  - AWSサービス統合のみ
```

### ベストプラクティス

```yaml
検証方法:
  - DNS検証を推奨
  - Route 53で自動化
  - メール検証は避ける

証明書設計:
  - ワイルドカード活用
  - SANで複数ドメイン統合
  - 環境ごとに分離

監視:
  - EventBridgeで期限監視
  - CloudWatch Alarms設定
  - インポート証明書は特に注意

セキュリティ:
  - 不要な証明書削除
  - IAMポリシーで制御
  - CloudTrailで監査
  - タグで管理

マルチリージョン:
  - CloudFrontは us-east-1
  - リージョナルサービスは各リージョン
  - 自動化で一括管理
```

## まとめ

**ACMの重要ポイント:**
- パブリック証明書は無料で自動更新
- DNS検証で完全自動化
- CloudFrontは us-east-1 のACM証明書必須
- ALB/API Gatewayは同一リージョン
- ワイルドカード証明書で管理簡素化
- EventBridgeで期限監視
- 秘密鍵は安全にACMが管理
- HSM使用でFIPS準拠
