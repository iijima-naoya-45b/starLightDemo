## AWS CLI

```bash
# Inspector有効化
aws inspector2 enable

# Finding一覧
aws inspector2 list-findings

# 抑制ルール作成
aws inspector2 create-filter \
  --action SUPPRESS \
  --filter-criteria file://filter.json
```
