## Amazon Cognito とは？


**ポケモンで例えると**: AWSを理解することは、新しい「わざ」を覚えるようなもの——使いこなせば、より強力な開発者になれます。

Cognitoは、Webアプリ・モバイルアプリのユーザー認証・認可サービスです。ユーザー管理を簡単に実装できます。

### 主要コンポーネント

```yaml
User Pools:
  - ユーザーディレクトリ
  - サインアップ/サインイン
  - MFA、パスワードポリシー
  - JWT発行

Identity Pools:
  - AWS認証情報取得
  - 一時クレデンシャル
  - ゲストアクセス
  - ソーシャルログイン統合
```

### User Pools主要機能

```yaml
認証:
  - Email/電話番号
  - ユーザー名/パスワード
  - MFA（SMS、TOTP）

ソーシャルログイン:
  - Google
  - Facebook
  - Amazon
  - Apple

SAML/OIDC:
  - エンタープライズID連携
  - Azure AD
  - Okta

カスタマイズ:
  - Lambda Trigger
  - UI カスタマイズ
  - カスタム属性
```

### Lambda Triggers

```yaml
Pre Sign-up:
  - サインアップ前処理
  - カスタムバリデーション

Post Confirmation:
  - 確認後処理
  - Welcome Email

Pre Authentication:
  - 認証前処理
  - IP制限

Post Authentication:
  - 認証後処理
  - ログ記録
```

### Identity Pools

```yaml
機能:
  - 一時AWS認証情報
  - IAMロール割り当て
  - ゲストアクセス

フェデレーション:
  - User Pools
  - ソーシャルログイン
  - SAML
  - 開発者認証
```

### セキュリティ

```yaml
MFA:
  - SMS
  - TOTP（Google Authenticator）

Advanced Security:
  - リスクベース認証
  - 異常検知
  - アカウント乗っ取り対策

パスワードポリシー:
  - 最小文字数
  - 複雑さ要件
  - 有効期限
```

### まとめ

**Cognitoの重要ポイント:**
- ユーザー認証・認可
- User Pools: ユーザー管理
- Identity Pools: AWS認証情報
- ソーシャルログイン、SAML対応
- MFA、Advanced Security
