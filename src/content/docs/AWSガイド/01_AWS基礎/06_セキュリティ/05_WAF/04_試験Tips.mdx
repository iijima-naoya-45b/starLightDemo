## SAA（ソリューションアーキテクト アソシエイト）

### 頻出ポイント

#### 1. WAF基本概念

```yaml
出題パターン:
  「SQLインジェクションから保護」

正解:
  - AWS WAF
  - マネージドルール
  - Layer 7保護

キーワード:
  ✅ SQLインジェクション → WAF
  ✅ XSS → WAF
  ✅ Webアプリケーション保護 → WAF
```

#### 2. レート制限

```yaml
シナリオ:
  「過剰なAPIリクエスト防止」

正解:
  - レートベースルール
  - 5分間の制限
  - IP単位

例:
  - 2,000リクエスト/5分
  - 超過時Block
```

#### 3. 適用先

```yaml
対応サービス:
  ✅ CloudFront
  ✅ ALB
  ✅ API Gateway
  ✅ AppSync
  
  ❌ NLB（非対応）
  ❌ EC2直接（非対応）
```

## SAP（ソリューションアーキテクト プロフェッショナル）

### 高度なシナリオ

#### 1. マルチアカウント管理

```yaml
要件:
  「組織全体でWAFポリシー統一」

設計:
  AWS Firewall Manager:
    - 一元管理
    - ポリシー自動適用
    - コンプライアンス確認
```

#### 2. Bot対策

```yaml
要件:
  「スクレイピングbot対策」

設計:
  - Bot Control有効化
  - CAPTCHA統合
  - レート制限併用
```

## よくある間違い

### 間違い 1: レイヤーの誤解

```yaml
❌ 誤り:
  「WAFでDDoS対策完璧」

✅ 正解:
  WAF: Layer 7
  Shield: Layer 3/4
  併用推奨
```

### 間違い 2: NLB対応の誤解

```yaml
❌ 誤り:
  「NLBにWAF適用可能」

✅ 正解:
  対応:
    - CloudFront
    - ALB
    - API Gateway
  
  非対応:
    - NLB
```
