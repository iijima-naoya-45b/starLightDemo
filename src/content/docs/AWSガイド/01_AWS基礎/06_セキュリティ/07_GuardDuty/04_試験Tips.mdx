## SAA（ソリューションアーキテクト アソシエイト）

### 頻出ポイント

```yaml
出題パターン:
  「脅威検知と自動対応」

正解:
  - GuardDuty
  - 機械学習ベース
  - 自動分析

キーワード:
  ✅ 脅威検知 → GuardDuty
  ✅ 異常検知 → GuardDuty
  ✅ 自動分析 → GuardDuty
```

## SAP（ソリューションアーキテクト プロフェッショナル）

### 高度なシナリオ

```yaml
組織全体のセキュリティ:
  要件:
    - マルチアカウント監視
    - 自動対応
    - 統合管理

  設計:
    - GuardDuty Organizations
    - EventBridge自動対応
    - Security Hub統合
```

## よくある間違い

```yaml
❌ 誤り:
  「GuardDutyで脆弱性スキャン」

✅ 正解:
  GuardDuty: 脅威検知
  Inspector: 脆弱性スキャン
```

## まとめ

**試験ポイント:**
- 脅威検知サービス
- 機械学習ベース
- 自動分析・通知
- Inspector との違い理解
