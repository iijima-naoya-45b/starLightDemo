## AWS CLI コマンド

```bash
# GuardDuty有効化
aws guardduty create-detector --enable

# Finding一覧
aws guardduty list-findings \
  --detector-id <detector-id>

# Finding詳細
aws guardduty get-findings \
  --detector-id <detector-id> \
  --finding-ids <finding-id>
```
