## Shield Advanced設定

### 有効化

```bash
# Shield Advanced 有効化（コンソール推奨）
# リソース保護設定
aws shield associate-drt-log-bucket \
  --log-bucket s3-bucket-name

# DRT アクセス許可
aws shield associate-drt-role \
  --role-arn arn:aws:iam::123456789012:role/DRTRole
```

```yaml
アーキテクチャ:
```
