## AWS Step Functions 完全ガイド

AWS Step Functionsは、複数のAWSサービスを組み合わせてサーバーレスワークフローを構築できるオーケストレーションサービスです。視覚的なワークフローで複雑なビジネスロジックを実装できます。

### Step Functionsの特徴

#### 1. 主要な特徴

**ワークフロー管理:**

- **視覚的な設計**: グラフィカルなワークフローエディタ
- **状態管理**: 各ステップの状態を自動管理
- **エラーハンドリング**: 自動リトライと例外処理
- **並列処理**: 複数タスクの並行実行

**統合:**

- **AWS統合**: Lambda、ECS、SNS、SQS、DynamoDB等
- **HTTP統合**: 外部APIの呼び出し
- **SDK統合**: 200以上のAWSサービスと直接統合

**実行モード:**

- **Standard**: 長時間実行（最大1年）、実行履歴保持
- **Express**: 高スループット（最大5分）、低コスト

#### 2. ワークフロータイプ

**Standard Workflows:**

```yaml
特徴:
  - 実行時間: 最大1年
  - 実行履歴: 90日間保持
  - 実行速度: 2000実行/秒/アカウント
  - 状態遷移: 4000/秒/アカウント
  - 価格: 状態遷移単位（$0.025/1000遷移）

適用シナリオ:
  - 長時間実行バッチ処理
  - 承認ワークフロー
  - 複雑なオーケストレーション
  - 監査が必要な処理
```

**Express Workflows:**

```yaml
特徴:
  - 実行時間: 最大5分
  - 実行履歴: CloudWatch Logsに記録
  - 実行速度: 100,000実行/秒/アカウント
  - 価格: 実行時間と回数（$1.00/百万リクエスト）

適用シナリオ:
  - 高頻度のイベント処理
  - IoTデータ処理
  - ストリーム処理
  - モバイルバックエンド
```

### Amazon States Language (ASL)

#### 1. 基本構造

```json
{
  "Comment": "ユーザー登録ワークフロー",
  "StartAt": "ValidateUser",
  "States": {
    "ValidateUser": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ValidateUser",
      "Next": "SaveToDynamoDB",
      "Catch": [
        {
          "ErrorEquals": ["ValidationError"],
          "Next": "ValidationFailed"
        }
      ],
      "Retry": [
        {
          "ErrorEquals": ["States.Timeout"],
          "IntervalSeconds": 2,
          "MaxAttempts": 3,
          "BackoffRate": 2.0
        }
      ]
    },
    "SaveToDynamoDB": {
      "Type": "Task",
      "Resource": "arn:aws:states:::dynamodb:putItem",
      "Parameters": {
        "TableName": "Users",
        "Item": {
          "userId": { "S.$": "$.userId" },
          "email": { "S.$": "$.email" },
          "createdAt": { "S.$": "$$.State.EnteredTime" }
        }
      },
      "Next": "SendWelcomeEmail"
    },
    "SendWelcomeEmail": {
      "Type": "Task",
      "Resource": "arn:aws:states:::sns:publish",
      "Parameters": {
        "TopicArn": "arn:aws:sns:ap-northeast-1:123456789012:WelcomeEmail",
        "Message.$": "$.email"
      },
      "End": true
    },
    "ValidationFailed": {
      "Type": "Fail",
      "Error": "ValidationError",
      "Cause": "ユーザー検証に失敗しました"
    }
  }
}
```

#### 2. 状態タイプ

**Task（タスク）:**

```json
{
  "ValidateInput": {
    "Type": "Task",
    "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:Validate",
    "TimeoutSeconds": 30,
    "HeartbeatSeconds": 10,
    "Next": "ProcessData"
  }
}
```

**Choice（条件分岐）:**

```json
{
  "CheckAge": {
    "Type": "Choice",
    "Choices": [
      {
        "Variable": "$.age",
        "NumericGreaterThanEquals": 20,
        "Next": "AdultProcessing"
      },
      {
        "Variable": "$.age",
        "NumericLessThan": 20,
        "Next": "MinorProcessing"
      }
    ],
    "Default": "UnknownAge"
  }
}
```

**Parallel（並列処理）:**

```json
{
  "ParallelProcessing": {
    "Type": "Parallel",
    "Branches": [
      {
        "StartAt": "ProcessImages",
        "States": {
          "ProcessImages": {
            "Type": "Task",
            "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ProcessImages",
            "End": true
          }
        }
      },
      {
        "StartAt": "ProcessVideos",
        "States": {
          "ProcessVideos": {
            "Type": "Task",
            "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ProcessVideos",
            "End": true
          }
        }
      }
    ],
    "Next": "CombineResults"
  }
}
```

**Map（繰り返し処理）:**

```json
{
  "ProcessBatch": {
    "Type": "Map",
    "ItemsPath": "$.items",
    "MaxConcurrency": 10,
    "Iterator": {
      "StartAt": "ProcessItem",
      "States": {
        "ProcessItem": {
          "Type": "Task",
          "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ProcessItem",
          "End": true
        }
      }
    },
    "Next": "CompleteBatch"
  }
}
```

**Wait（待機）:**

```json
{
  "WaitForApproval": {
    "Type": "Wait",
    "Seconds": 3600,
    "Next": "CheckApprovalStatus"
  },
  "WaitUntilTimestamp": {
    "Type": "Wait",
    "Timestamp": "2026-01-15T10:00:00Z",
    "Next": "StartScheduledTask"
  },
  "WaitDynamic": {
    "Type": "Wait",
    "SecondsPath": "$.waitTime",
    "Next": "ContinueProcess"
  }
}
```

**Pass（データ変換）:**

```json
{
  "TransformData": {
    "Type": "Pass",
    "Result": {
      "status": "processed",
      "timestamp": "2026-01-15T10:00:00Z"
    },
    "ResultPath": "$.metadata",
    "Next": "SaveResult"
  }
}
```

**Succeed/Fail（終了状態）:**

```json
{
  "Success": {
    "Type": "Succeed"
  },
  "Failure": {
    "Type": "Fail",
    "Error": "ProcessingError",
    "Cause": "データ処理に失敗しました"
  }
}
```

### 実装例

#### 1. 画像処理ワークフロー

```json
{
  "Comment": "画像アップロード処理ワークフロー",
  "StartAt": "ValidateImage",
  "States": {
    "ValidateImage": {
      "Type": "Task",
      "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ValidateImage",
      "Next": "CheckImageSize"
    },
    "CheckImageSize": {
      "Type": "Choice",
      "Choices": [
        {
          "Variable": "$.size",
          "NumericGreaterThan": 10485760,
          "Next": "ImageTooLarge"
        }
      ],
      "Default": "ProcessImage"
    },
    "ProcessImage": {
      "Type": "Parallel",
      "Branches": [
        {
          "StartAt": "CreateThumbnail",
          "States": {
            "CreateThumbnail": {
              "Type": "Task",
              "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:CreateThumbnail",
              "End": true
            }
          }
        },
        {
          "StartAt": "ExtractMetadata",
          "States": {
            "ExtractMetadata": {
              "Type": "Task",
              "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ExtractMetadata",
              "End": true
            }
          }
        },
        {
          "StartAt": "RunImageRecognition",
          "States": {
            "RunImageRecognition": {
              "Type": "Task",
              "Resource": "arn:aws:states:::aws-sdk:rekognition:detectLabels",
              "Parameters": {
                "Image": {
                  "S3Object": {
                    "Bucket.$": "$.bucket",
                    "Name.$": "$.key"
                  }
                }
              },
              "End": true
            }
          }
        }
      ],
      "Next": "SaveResults"
    },
    "SaveResults": {
      "Type": "Task",
      "Resource": "arn:aws:states:::dynamodb:putItem",
      "Parameters": {
        "TableName": "Images",
        "Item": {
          "imageId": { "S.$": "$.imageId" },
          "metadata": { "S.$": "States.JsonToString($[1])" },
          "labels": { "S.$": "States.JsonToString($[2].Labels)" },
          "thumbnailUrl": { "S.$": "$[0].thumbnailUrl" }
        }
      },
      "Next": "NotifyCompletion"
    },
    "NotifyCompletion": {
      "Type": "Task",
      "Resource": "arn:aws:states:::sns:publish",
      "Parameters": {
        "TopicArn": "arn:aws:sns:ap-northeast-1:123456789012:ImageProcessed",
        "Message.$": "$"
      },
      "End": true
    },
    "ImageTooLarge": {
      "Type": "Fail",
      "Error": "ImageTooLarge",
      "Cause": "画像サイズが10MBを超えています"
    }
  }
}
```

### エラーハンドリング

#### 1. Retry（リトライ）

```json
{
  "ProcessData": {
    "Type": "Task",
    "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ProcessData",
    "Retry": [
      {
        "ErrorEquals": ["States.Timeout"],
        "IntervalSeconds": 2,
        "MaxAttempts": 3,
        "BackoffRate": 2.0
      },
      {
        "ErrorEquals": ["States.TaskFailed"],
        "IntervalSeconds": 1,
        "MaxAttempts": 2,
        "BackoffRate": 1.5
      },
      {
        "ErrorEquals": ["States.ALL"],
        "IntervalSeconds": 5,
        "MaxAttempts": 1,
        "BackoffRate": 1.0
      }
    ],
    "Next": "NextState"
  }
}
```

#### 2. Catch（例外処理）

```json
{
  "ProcessPayment": {
    "Type": "Task",
    "Resource": "arn:aws:lambda:ap-northeast-1:123456789012:function:ProcessPayment",
    "Catch": [
      {
        "ErrorEquals": ["PaymentDeclined"],
        "ResultPath": "$.error",
        "Next": "NotifyPaymentDeclined"
      },
      {
        "ErrorEquals": ["InsufficientFunds"],
        "ResultPath": "$.error",
        "Next": "NotifyInsufficientFunds"
      },
      {
        "ErrorEquals": ["States.ALL"],
        "ResultPath": "$.error",
        "Next": "GeneralError"
      }
    ],
    "Next": "PaymentSuccess"
  }
}
```

### ベストプラクティス

#### 1. コスト最適化

```yaml
Standard vs Express:
  Standard:
    - 長時間実行
    - 実行履歴が必要
    - 監査要件
  
  Express:
    - 高頻度実行
    - 短時間処理（5分以内）
    - コスト重視

Lambda統合:
  - 適切なメモリ設定
  - 短いタイムアウト
  - 非同期実行の活用
```

#### 2. 設計パターン

```yaml
Saga Pattern（分散トランザクション）:
  - 各ステップで補償アクション定義
  - Catchで補償フロー実行
  - データ整合性を保証

Fan-out/Fan-in:
  - Parallelで並列処理
  - Mapで大量データ処理
  - 結果を集約

Human-in-the-Loop:
  - Task Tokenで承認待ち
  - コールバックで再開
  - タイムアウト処理
```

### まとめ

**Step Functionsの主要な利点:**

- **視覚的なワークフロー**: 複雑なロジックを理解しやすく
- **エラーハンドリング**: 自動リトライと例外処理
- **AWS統合**: 200以上のサービスと直接統合
- **スケーラビリティ**: 自動スケーリング
- **コスト効率**: Express Workflowsで低コスト

**SAA/SAP試験での重要ポイント:**

1. **ワークフロータイプ**: Standard vs Express
2. **状態タイプ**: Task, Choice, Parallel, Map, Wait
3. **エラーハンドリング**: Retry, Catch
4. **統合**: Lambda, ECS, SNS, SQS, DynamoDB
5. **ユースケース**: 承認フロー、バッチ処理、ETL、マイクロサービス

Step Functionsは、サーバーレスワークフローの実装に最適なサービスです。複雑なビジネスロジックを視覚的に設計・管理できます。
