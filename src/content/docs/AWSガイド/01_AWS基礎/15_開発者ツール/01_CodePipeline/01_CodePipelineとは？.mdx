## AWS CodePipeline とは？

CodePipelineは、継続的デリバリー（CI/CD）のためのフルマネージドサービスです。コードのビルド、テスト、デプロイを自動化します。

### 基本概念

```yaml
パイプライン:
  - ワークフロー定義
  - 自動化されたリリースプロセス
  - ステージとアクションで構成

ステージ:
  - 論理的なグループ
  - 例: Source、Build、Test、Deploy
  - 順次実行

アクション:
  - 個々のタスク
  - 並列実行可能
  - サービス統合
```

### パイプライン構造

```yaml
パイプライン構成要素:
  Source:
    - CodeCommit
    - GitHub
    - S3
    - Bitbucket

  Build:
    - CodeBuild
    - Jenkins
    - CloudBees

  Test:
    - CodeBuild
    - サードパーティテストツール

  Deploy:
    - CodeDeploy
    - ECS
    - S3
    - CloudFormation
    - Elastic Beanstalk
```

### ステージとアクション

```yaml
ステージ構成:
  名前: Source
  アクション:
    - ソース取得
    - トリガー設定

  名前: Build
  アクション:
    - コンパイル
    - テスト実行
    - アーティファクト生成

  名前: Deploy
  アクション:
    - デプロイ実行
    - 環境更新
    - 承認ゲート（オプション）
```

### 主要機能

```yaml
自動トリガー:
  - コミット検知
  - スケジュール実行
  - 手動実行

並列実行:
  - 複数アクション同時実行
  - 効率的なパイプライン

承認プロセス:
  - 手動承認ステージ
  - SNS通知
  - 本番デプロイ前の確認

クロスリージョン:
  - 複数リージョンデプロイ
  - グローバル展開

アーティファクト管理:
  - S3自動保存
  - ステージ間受け渡し
```

### 統合サービス

```yaml
AWS サービス:
  - CodeCommit: リポジトリ
  - CodeBuild: ビルド
  - CodeDeploy: デプロイ
  - CloudFormation: IaC
  - ECS/EKS: コンテナ
  - Lambda: サーバーレス

サードパーティ:
  - GitHub: ソース管理
  - Jenkins: ビルド
  - Terraform: IaC
```

### 料金

**パイプライン実行単位の課金**

| 項目 | 価格 | 備考 |
|---|---|---|
| **アクティブパイプライン** | $1.00/月 | パイプライン作成費用 |
| **パイプライン実行** | 無料（最初の1回/月） | 月1回まで無料 |
| **追加実行** | $0 | 1回目以降の実行は無料 |

**料金例:**

| 構成 | 月額料金 | 備考 |
|---|---|---|
| パイプライン1つ + 月10回実行 | $1.00 | 基本料金のみ |
| パイプライン3つ + 月50回実行 | $3.00 | パイプライン数分 |
| パイプライン10つ + 月200回実行 | $10.00 | パイプライン数×$1 |

**関連サービス料金:**
- CodeBuild: ビルド時間に応じた課金（$0.005/分〜）
- CodeDeploy: EC2/オンプレミスは無料、ECS/Lambdaは無料
- S3: アーティファクト保存料金
- データ転送: クロスリージョンの場合

**無料利用枠:**
- パイプライン: 1つまで無料（最初の30日間）
- CodeBuild: 月100分まで無料
- CodeDeploy: 無料

**コストメリット:**
- パイプライン数のみで課金、実行回数は無制限（1回目以降）
- 手動デプロイの人件費削減
- エラー早期発見でコスト削減

### まとめ

**CodePipelineの重要ポイント:**
- フルマネージドCI/CDサービス
- ステージとアクションで構成
- 多様なサービス統合
- 自動トリガー対応
- パイプライン単位の課金
