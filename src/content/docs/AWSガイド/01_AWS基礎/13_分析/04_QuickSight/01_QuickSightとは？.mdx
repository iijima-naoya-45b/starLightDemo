## Amazon QuickSight とは？

QuickSightは、データを視覚化し、インタラクティブなダッシュボードを作成できるクラウドネイティブなBIサービスです。

### 主要機能

#### 1. SPICE（Super-fast, Parallel, In-memory Calculation Engine）

```yaml
概要:
  - インメモリ計算エンジン
  - 高速データ処理
  - 自動スケーリング
  - 列指向ストレージ

特徴:
  - ミリ秒単位の応答
  - 数百万行の処理
  - 自動圧縮（1/10に削減）
  - 増分リフレッシュ対応

容量:
  - エンタープライズ: 500GB/ユーザー
  - スタンダード: 10GB/ユーザー
  - 追加購入可能
```

#### 2. データソース

```yaml
AWS サービス:
  - Amazon Athena
  - Amazon Redshift
  - Amazon RDS（MySQL、PostgreSQL、SQL Server）
  - Amazon Aurora
  - Amazon S3（マニフェストファイル経由）
  - AWS IoT Analytics
  - Amazon OpenSearch Service

サードパーティ:
  - Salesforce
  - Snowflake
  - Teradata
  - Jira
  - ServiceNow

ファイル:
  - CSV / TSV
  - ELF / CLF（ログ）
  - JSON
  - XLSX
```

#### 3. ビジュアライゼーション

```yaml
基本グラフ:
  - 棒グラフ（縦・横）
  - 折れ線グラフ
  - 円グラフ
  - 散布図
  - ヒートマップ

高度なビジュアル:
  - ツリーマップ
  - ピボットテーブル
  - KPI（主要指標）
  - ゲージ
  - ウォーターフォールチャート

地理的ビジュアル:
  - マップ（地図）
  - ポイントマップ
  - ヒートマップ

カスタム:
  - パラメータ制御
  - 計算フィールド
  - カスタムSQL
```

### ダッシュボード機能

```yaml
インタラクティブ機能:
  フィルター:
    - データセットフィルター
    - ビジュアルフィルター
    - クロスフィルター
  
  パラメータ:
    - 動的な値選択
    - ドリルダウン
    - URLアクションパラメータ
  
  アクション:
    - フィルターアクション
    - URL アクション
    - ナビゲーションアクション

共有・公開:
  - ダッシュボード公開
  - メール配信（スケジュール）
  - 埋め込み（Webサイト・アプリ）
  - PDF/CSVエクスポート
```

### QuickSight Q（自然言語クエリ）

```yaml
概要:
  - 自然言語でデータ質問
  - AIが自動でビジュアライゼーション生成
  - ビジネスユーザー向け

機能:
  - 日本語対応
  - 質問の候補提示
  - コンテキスト理解
  - 継続的な学習

例:
  質問: "今月の売上トップ10の商品は？"
  → 自動で棒グラフ生成
  
  質問: "地域別の顧客分布を見せて"
  → 自動でマップ生成
```

### ML Insights（機械学習）

```yaml
異常検知:
  - 時系列データの異常検出
  - 自動アラート
  - 根本原因分析

予測:
  - 時系列予測
  - トレンド予測
  - 信頼区間表示

自動ナラティブ:
  - データの自然言語説明
  - 主要な洞察自動抽出
  - ダッシュボードに統合

寄与分析:
  - 変化の要因分析
  - ドライバー特定
  - 影響度計算
```

### ユーザー管理

```yaml
認証:
  IAM:
    - AWSアカウント統合
    - ロールベースアクセス
  
  Active Directory:
    - AD FS統合
    - シングルサインオン
  
  SAML 2.0:
    - IdP統合（Okta、Azure ADなど）

エディション:
  Standard:
    - 基本BI機能
    - メール配信
    - 行レベルセキュリティ（RLS）
  
  Enterprise:
    - Standard機能すべて
    - Active Directory統合
    - 暗号化（KMS）
    - SPICE容量増加
    - ML Insights
    - QuickSight Q

ロール:
  Admin:
    - すべての権限
    - ユーザー管理
  
  Author:
    - ダッシュボード作成
    - データセット作成
  
  Reader:
    - ダッシュボード閲覧のみ
```

### 埋め込み分析

```yaml
概要:
  - ダッシュボードをWebアプリに埋め込み
  - シームレスなユーザー体験
  - ホワイトラベル対応

実装方法:
  SDK:
    - JavaScript SDK
    - 認証トークン取得
    - iframe埋め込み
  
  API:
    - GenerateEmbedUrlForRegisteredUser
    - GenerateEmbedUrlForAnonymousUser

セキュリティ:
  - 行レベルセキュリティ（RLS）
  - ユーザー識別
  - セッション管理
  - カスタムドメイン

料金:
  - Session-based pricing
  - 30分セッション単位課金
```

### 行レベルセキュリティ（RLS）

```yaml
概要:
  - ユーザーごとにデータフィルター
  - データセットレベルで制御
  - きめ細かなアクセス制御

設定方法:
  マニフェストファイル:
    - CSV形式
    - ユーザー名とフィルター条件
  
  データベース:
    - テーブルベースRLS
    - 動的フィルター

例:
  営業担当者:
    - 自分の担当地域のみ表示
  
  マネージャー:
    - チーム全体のデータ表示
  
  経営層:
    - 全データアクセス
```

### データ更新

```yaml
SPICEリフレッシュ:
  スケジュール:
    - 時間指定
    - 日次・週次・月次
    - 最小15分間隔（Enterprise）
  
  増分リフレッシュ:
    - 新規データのみ追加
    - 処理時間短縮
    - コスト削減

直接クエリ:
  - SPICEを経由しない
  - リアルタイムデータ
  - データソース直接接続
  - パフォーマンス考慮必要
```

### セキュリティ

```yaml
暗号化:
  保管時:
    - SPICE自動暗号化
    - KMS統合（Enterprise）
  
  転送中:
    - TLS/SSL

アクセス制御:
  - IAMポリシー
  - リソースレベル権限
  - 行レベルセキュリティ（RLS）
  - 列レベルセキュリティ（CLS）

監査:
  - CloudTrail統合
  - アクセスログ
  - ダッシュボード利用状況
```

### QuickSight vs 他のBIツール

```yaml
QuickSight:
  メリット:
    - AWS統合
    - サーバーレス
    - 従量課金
    - 埋め込み対応
    - ML Insights
  
  デメリット:
    - カスタマイズ制限
    - 複雑な計算に制約

Tableau:
  メリット:
    - 高度なビジュアライゼーション
    - 豊富な機能
    - 大規模コミュニティ
  
  デメリット:
    - 高コスト
    - インフラ管理必要

Power BI:
  メリット:
    - Microsoft統合
    - Excel親和性
    - 豊富な機能
  
  デメリット:
    - AWS統合弱い
    - ライセンス管理

Looker:
  メリット:
    - データモデリング強力
    - バージョン管理
  
  デメリット:
    - 学習コスト高
    - セットアップ複雑
```

### まとめ

**QuickSightの重要ポイント:**
- クラウドネイティブBIサービス
- SPICE で高速インメモリ処理
- 多様なデータソース接続
- ML Insights で異常検知・予測
- QuickSight Q で自然言語クエリ
- 埋め込み分析対応
- 行レベルセキュリティ（RLS）
- 従量課金でコスト効率
