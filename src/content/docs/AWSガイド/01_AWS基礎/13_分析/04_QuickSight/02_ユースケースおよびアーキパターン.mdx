## ユースケース

### 1. リアルタイムダッシュボード

```yaml
シナリオ:
  - IoTセンサーデータの可視化
  - Webアプリケーションメトリクス監視
  - リアルタイム売上ダッシュボード

実装:
  1. Kinesis Data Firehose でデータ収集
  2. S3 に保存 & Athena でクエリ
  3. QuickSight で SPICE リフレッシュ（15分間隔）
  4. ダッシュボードで可視化

特徴:
  - 準リアルタイム（数分遅延）
  - 自動更新
  - 高速表示（SPICE）
```

### 2. 埋め込み分析（Embedded Analytics）

```yaml
シナリオ:
  - SaaS アプリケーション内での分析機能
  - 顧客向けレポートポータル
  - マルチテナントダッシュボード

実装:
  1. QuickSight ダッシュボード作成
  2. 行レベルセキュリティ（RLS）設定
  3. SDK で埋め込みURL生成
  4. Webアプリに iframe 埋め込み

セキュリティ:
  - ユーザーごとにデータフィルター
  - シングルサインオン統合
  - セッション管理

メリット:
  - ホワイトラベル対応
  - カスタマイズ可能
  - スケーラブル
```

### 3. セルフサービスBI

```yaml
シナリオ:
  - ビジネスユーザーが自分でレポート作成
  - アドホック分析

実装:

ユーザー:

      - tenant_id 取得

      - GenerateEmbedUrlForRegisteredUser API
      - RLS 自動適用
      - iframe で表示

実装例:
  # Lambda 関数（埋め込みURL生成）
  import boto3
  
  quicksight = boto3.client('quicksight')
  
  def generate_embed_url(user_arn, tenant_id):
      response = quicksight.generate_embed_url_for_registered_user(
          AwsAccountId='123456789012',
          SessionLifetimeInMinutes=600,
          UserArn=user_arn,
          ExperienceConfiguration={
              'Dashboard': {
                  'InitialDashboardId': 'dashboard-id'
              }
          }
      )
      return response['EmbedUrl']

セキュリティ:
  - tenant_id による RLS
  - セッション管理
  - API認証
```

## 実装例

### データセット作成（Athena）

```yaml
# データセット接続
データソース:
  名前: athena-datasource
  タイプ: Athena
  ワークグループ: primary

データセット:
  名前: sales_analysis
  ソース: athena-datasource
  
カスタムSQL:
  SELECT 
    DATE_TRUNC('day', order_date) as date,
    product_category,
    region,
    SUM(sales_amount) as total_sales,
    COUNT(DISTINCT customer_id) as unique_customers,
    AVG(sales_amount) as avg_order_value
  FROM sales_data
  WHERE year = '2024'
  GROUP BY 1, 2, 3

SPICEモード:
  - インポート: データをSPICEにロード
  - 直接クエリ: Athenaに毎回クエリ
```

### 計算フィールド作成

```sql
-- 前年比成長率
ifelse(
  sum({total_sales} OVER ([date ASC] ROWS BETWEEN 365 PRECEDING AND 365 PRECEDING)) > 0,
  (sum({total_sales}) - sum({total_sales} OVER ([date ASC] ROWS BETWEEN 365 PRECEDING AND 365 PRECEDING))) 
    / sum({total_sales} OVER ([date ASC] ROWS BETWEEN 365 PRECEDING AND 365 PRECEDING)) * 100,
  NULL
)

-- 累積売上
sum({total_sales}) OVER ([date ASC] ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)

-- 移動平均（7日間）
avg({total_sales}) OVER ([date ASC] ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)

-- カテゴリ別シェア
sum({total_sales}) / sumOver(sum({total_sales}), [{date}], PRE_AGG) * 100

-- 条件付き集計
sumIf({sales_amount}, {region} = 'East')
```

```python
# Python（Flask）バックエンド
import boto3
from flask import Flask, jsonify

app = Flask(__name__)
quicksight = boto3.client('quicksight', region_name='us-east-1')

@app.route('/api/get-quicksight-embed-url')
def get_embed_url():
    # ユーザー認証（実装による）
    user_id = get_current_user_id()
    tenant_id = get_user_tenant_id(user_id)
    
    # QuickSight ユーザーARN
    user_arn = f"arn:aws:quicksight:us-east-1:123456789012:user/default/{user_id}"
    
    try:
        response = quicksight.generate_embed_url_for_registered_user(
            AwsAccountId='123456789012',
            SessionLifetimeInMinutes=600,
            UserArn=user_arn,
            ExperienceConfiguration={
                'Dashboard': {
                    'InitialDashboardId': 'your-dashboard-id'
                }
            },
            AllowedDomains=['https://your-domain.com']
        )
        
        return jsonify({
            'embedUrl': response['EmbedUrl'],
            'requestId': response['RequestId']
        })
    except Exception as e:
        return jsonify({'error': str(e)}), 500
```

### SPICE リフレッシュ自動化

```python
# Lambda 関数
import boto3

quicksight = boto3.client('quicksight')

def lambda_handler(event, context):
    account_id = '123456789012'
    data_set_id = 'your-dataset-id'
    
    try:
        response = quicksight.create_ingestion(
            DataSetId=data_set_id,
            IngestionId=f'ingestion-{context.request_id}',
            AwsAccountId=account_id
        )
        
        return {
            'statusCode': 200,
            'body': f"SPICE refresh started: {response['IngestionId']}"
        }
    except Exception as e:
        return {
            'statusCode': 500,
            'body': f"Error: {str(e)}"
        }
```
