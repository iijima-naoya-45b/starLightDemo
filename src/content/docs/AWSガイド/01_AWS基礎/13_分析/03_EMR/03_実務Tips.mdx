```yaml
  汎用（Spark、Hive）:
    - m5シリーズ
    - バランス型
  
  コンピューティング集約:
    - c5シリーズ
    - CPU最適化
  
  メモリ集約（Presto、Spark SQL）:
    - r5シリーズ
    - メモリ最適化
  
  機械学習:
    - p3シリーズ（GPU）
    - g4シリーズ（GPU、コスト効率）

ストレージ:
  HDFS（Core Node）:
    - EBS: gp3
    - サイズ: 100-500GB
    - 中間データのみ
  
  S3（EMRFS）:
    - 入力データ
    - 最終結果
    - 永続データ
```

### PySpark コード例

```python
# 基本的なSparkジョブ
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, to_date, sum, count

# SparkSession作成
spark = SparkSession.builder \
    .appName("ETL Job") \
    .getOrCreate()

# S3からデータ読み込み
df = spark.read \
    .format("parquet") \
    .load("s3://my-bucket/input/")

# データ処理
result = df \
    .filter(col("status") == "active") \
    .withColumn("date", to_date(col("timestamp"))) \
    .groupBy("date", "category") \
    .agg(
        sum("amount").alias("total_amount"),
        count("*").alias("count")
    ) \
    .orderBy("date", "category")

# 結果をS3に保存（Parquet形式、パーティション）
result.write \
    .mode("overwrite") \
    .partitionBy("date") \
    .format("parquet") \
    .option("compression", "snappy") \
    .save("s3://my-bucket/output/")

spark.stop()

# 複数ソース結合
# S3からデータ読み込み
transactions = spark.read.parquet("s3://bucket/transactions/")
customers = spark.read.parquet("s3://bucket/customers/")

# DynamoDBから読み込み
products = spark.read \
    .format("dynamodb") \
    .option("tableName", "products") \
    .load()

# 結合処理
result = transactions \
    .join(customers, "customer_id") \
    .join(products, "product_id") \
    .select(
        "transaction_id",
        "customer_name",
        "product_name",
        "amount",
        "timestamp"
    )

# パフォーマンス最適化
# キャッシング
df.cache()

# パーティション調整
df = df.repartition(100)

# ブロードキャスト結合（小さいテーブル）
from pyspark.sql.functions import broadcast
result = large_df.join(broadcast(small_df), "key")

# ウィンドウ関数
from pyspark.sql.window import Window
from pyspark.sql.functions import row_number

window_spec = Window.partitionBy("category").orderBy(col("amount").desc())
top_items = df.withColumn("rank", row_number().over(window_spec)) \
    .filter(col("rank") <= 10)
```
