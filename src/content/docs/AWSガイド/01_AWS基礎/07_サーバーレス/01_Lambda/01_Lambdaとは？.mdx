## AWS Lambda とは？

AWS Lambdaは、サーバーレスコンピューティングサービスです。サーバー管理不要で、イベント駆動でコードを実行できます。

### 基本概念

```yaml
特徴:
  - サーバー管理不要
  - 自動スケーリング
  - 従量課金（実行時間のみ）
  - イベント駆動
  - 100msから課金

制限:
  メモリ: 128MB 〜 10,240MB
  タイムアウト: 最大15分
  一時ストレージ: /tmp 最大10GB
  デプロイパッケージ: 50MB（zip）、250MB（解凍後）
  同時実行数: 1,000（デフォルト、上限緩和可能）
```

### ランタイム

```yaml
対応言語:
  - Node.js: 18, 20
  - Python: 3.9, 3.10, 3.11, 3.12
  - Java: 8, 11, 17, 21
  - .NET: 6, 8
  - Go: 1.x
  - Ruby: 3.2, 3.3
  - カスタムランタイム（任意言語）
```

### 料金

```yaml
リクエスト料金:
  - $0.20 / 100万リクエスト
  - 月100万リクエスト無料枠

実行時間料金:
  - GB秒単位
  - $0.0000166667 / GB秒
  - 月40万GB秒無料枠

例（128MB、100ms実行）:
  - 100万リクエスト: $0.20 + $0.21 = $0.41
```

### トリガー

```yaml
AWS統合:
  - API Gateway: REST API
  - ALB: HTTP(S)リクエスト
  - S3: オブジェクト作成/削除
  - DynamoDB Streams: テーブル変更
  - SNS/SQS: メッセージ
  - EventBridge: スケジュール、イベント
  - Kinesis: ストリーミング
  - CloudWatch Logs: ログフィルタ
```

### 実行環境

```yaml
コールドスタート:
  - 初回実行時の遅延
  - 数百ms 〜 数秒
  - 対策: Provisioned Concurrency

ウォームスタート:
  - 実行環境再利用
  - 数ms

/tmp:
  - 一時ストレージ
  - 最大10GB
  - 実行環境間で共有可能
```

### まとめ

**Lambdaの重要ポイント:**
- サーバーレス、自動スケーリング
- イベント駆動アーキテクチャ
- 従量課金でコスト効率
- 15分制限に注意
- コールドスタート対策
