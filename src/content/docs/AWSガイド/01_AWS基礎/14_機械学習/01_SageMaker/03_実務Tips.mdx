## AWS CLI コマンド

### モデル管理

```bash
# モデル作成
aws sagemaker create-model \
  --model-name my-model \
  --primary-container '{
    "Image": "763104351884.dkr.ecr.ap-northeast-1.amazonaws.com/pytorch-inference:2.0-cpu",
    "ModelDataUrl": "s3://my-bucket/model.tar.gz"
  }' \
  --execution-role-arn arn:aws:iam::123456789012:role/SageMakerRole

# モデル一覧
aws sagemaker list-models

# モデル詳細
aws sagemaker describe-model --model-name my-model

# モデル削除
aws sagemaker delete-model --model-name my-model
```

### トレーニングジョブ

```bash
# トレーニングジョブ作成
aws sagemaker create-training-job \
  --training-job-name my-training-job \
  --algorithm-specification '{
    "TrainingImage": "683313688378.dkr.ecr.ap-northeast-1.amazonaws.com/sagemaker-xgboost:1.5-1",
    "TrainingInputMode": "File"
  }' \
  --role-arn arn:aws:iam::123456789012:role/SageMakerRole \
  --input-data-config '[
    {
      "ChannelName": "train",
      "DataSource": {
        "S3DataSource": {
          "S3DataType": "S3Prefix",
          "S3Uri": "s3://my-bucket/train/",
          "S3DataDistributionType": "FullyReplicated"
        }
      },
      "ContentType": "text/csv"
    }
  ]' \
  --output-data-config '{
    "S3OutputPath": "s3://my-bucket/output/"
  }' \
  --resource-config '{
    "InstanceType": "ml.m5.xlarge",
    "InstanceCount": 2,
    "VolumeSizeInGB": 30
  }' \
  --stopping-condition '{
    "MaxRuntimeInSeconds": 86400
  }' \
  --hyper-parameters '{
    "max_depth": "5",
    "eta": "0.2",
    "objective": "binary:logistic",
    "num_round": "100"
  }'

# トレーニングジョブ状態確認
aws sagemaker describe-training-job --training-job-name my-training-job

# トレーニングジョブ一覧
aws sagemaker list-training-jobs --max-results 10

# トレーニングジョブ停止
aws sagemaker stop-training-job --training-job-name my-training-job
```

### エンドポイント管理

```bash
# エンドポイント設定作成
aws sagemaker create-endpoint-config \
  --endpoint-config-name my-endpoint-config \
  --production-variants '[
    {
      "VariantName": "AllTraffic",
      "ModelName": "my-model",
      "InstanceType": "ml.m5.xlarge",
      "InitialInstanceCount": 2,
      "InitialVariantWeight": 1.0
    }
  ]'

# エンドポイント作成
aws sagemaker create-endpoint \
  --endpoint-name my-endpoint \
  --endpoint-config-name my-endpoint-config

# エンドポイント状態確認
aws sagemaker describe-endpoint --endpoint-name my-endpoint

# エンドポイント一覧
aws sagemaker list-endpoints

# エンドポイント更新
aws sagemaker update-endpoint \
  --endpoint-name my-endpoint \
  --endpoint-config-name my-endpoint-config-v2

# エンドポイント削除
aws sagemaker delete-endpoint --endpoint-name my-endpoint
aws sagemaker delete-endpoint-config --endpoint-config-name my-endpoint-config

# 推論実行
aws sagemaker-runtime invoke-endpoint \
  --endpoint-name my-endpoint \
  --content-type application/json \
  --body '{"instances": [[1.0, 2.0, 3.0, 4.0]]}' \
  output.json

cat output.json
```

### バッチ変換

```bash
# バッチ変換ジョブ作成
aws sagemaker create-transform-job \
  --transform-job-name my-batch-transform \
  --model-name my-model \
  --transform-input '{
    "DataSource": {
      "S3DataSource": {
        "S3DataType": "S3Prefix",
        "S3Uri": "s3://my-bucket/batch-input/"
      }
    },
    "ContentType": "text/csv",
    "SplitType": "Line"
  }' \
  --transform-output '{
    "S3OutputPath": "s3://my-bucket/batch-output/",
    "AssembleWith": "Line"
  }' \
  --transform-resources '{
    "InstanceType": "ml.m5.xlarge",
    "InstanceCount": 5
  }'

# バッチ変換状態確認
aws sagemaker describe-transform-job --transform-job-name my-batch-transform

# バッチ変換ジョブ一覧
aws sagemaker list-transform-jobs
```

## トラブルシューティング

```yaml
よくある問題:

1. ResourceLimitExceeded:
   原因:
     - インスタンス数上限
     - サービスクォータ
   
   対処:
     - Service Quotas確認
     - 上限緩和リクエスト
     - リージョン変更検討

2. Training Job Failed:
   原因:
     - データ形式エラー
     - ハイパーパラメータ不適切
     - メモリ不足
   
   対処:
     - CloudWatch Logsチェック
     - データ検証
     - インスタンスサイズ増加
     - エラーハンドリング追加

3. Endpoint Latency高い:
   原因:
     - モデルサイズ大きい
     - 前処理重い
     - インスタンス不足
   
   対処:
     - モデル最適化（Neo）
     - Elastic Inference
     - インスタンスサイズ増加
     - Auto Scaling調整

4. Out of Memory:
   原因:
     - バッチサイズ大きい
     - モデルサイズ大きい
     - データ量多い
   
   対処:
     - バッチサイズ削減
     - メモリ最適化インスタンス
     - モデル並列
     - グラディエントチェックポイント

5. コールドスタート遅延:
   原因:
     - サーバーレス推論
     - マルチモデルエンドポイント
     - 大きなモデル
   
   対処:
     - 最小インスタンス数設定
     - モデルサイズ削減
     - ウォームアップリクエスト
     - リアルタイムエンドポイント検討
```

## セキュリティ

```yaml
IAMロール:
  SageMaker実行ロール:
    必須権限:
      - s3:GetObject, s3:PutObject
      - logs:CreateLogGroup, logs:CreateLogStream
      - ecr:GetAuthorizationToken, ecr:BatchGetImage
      - cloudwatch:PutMetricData
    
    オプション:
      - kms:Decrypt, kms:Encrypt（暗号化時）
      - vpc:*（VPC使用時）

暗号化:
  保管時:
    - S3: KMS暗号化
    - EBS: 自動暗号化
    - Model Artifacts: KMS
  
  転送中:
    - HTTPS/TLS
    - VPC内通信

VPC設定:
  推奨構成:
    - プライベートサブネット
    - VPCエンドポイント（S3, ECR, CloudWatch）
    - セキュリティグループ
    - NATゲートウェイ（外部アクセス時）
  
  制約:
    - インターネットアクセス不可
    - VPCエンドポイント必須
    - コスト増加

ネットワーク分離:
  - トレーニングジョブVPC
  - エンドポイントVPC
  - セキュリティグループ制御
  - PrivateLink使用
```
