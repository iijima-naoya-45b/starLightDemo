## ユースケース

### 1. 画像分類モデルの構築

```yaml
シナリオ:
  - S3の画像データから分類モデル構築
  - リアルタイム推論API提供
  - モデル精度の継続監視

実装:
  1. Data Wrangler でデータ前処理
  2. Training Job で学習（組み込みアルゴリズム）
  3. リアルタイムエンドポイント デプロイ
  4. Model Monitor で精度監視
```

### 2. 需要予測

```yaml
シナリオ:
  - 過去の売上データから需要予測
  - バッチ推論で日次予測
  - 定期的なモデル再学習

実装:
  ソース: S3 / Redshift（売上データ）
  Training:
    - DeepAR（時系列予測）
    - Autopilot（AutoML）
  推論:
    - バッチ変換（日次実行）
  Pipeline:
    - 自動再トレーニング（週次）
```

### 3. 不正検知システム

```yaml
シナリオ:
  - リアルタイム取引の不正検知
  - 低レイテンシ要求（< 50ms）
  - 高スループット

実装:
  データ収集:
    - Kinesis Data Streams
    - Lambda で前処理
  
  モデル:
    - XGBoost（二値分類）
    - Feature Store活用
  
  推論:
    - リアルタイムエンドポイント
    - Auto Scaling
    - Multi-AZ配置
  
  監視:
    - Model Monitor（品質監視）
    - CloudWatch Alarms
    - 異常検知時の自動対応
```

## アーキテクチャパターン

### パターン1: 基本的なMLワークフロー

```yaml
構成:
  データ準備:
    S3（生データ）
      ↓
    SageMaker Processing Job
      - データクレンジング
      - 特徴量エンジニアリング
      - 訓練/検証/テスト分割
      ↓
    S3（前処理済み）
  
  モデル開発:
    SageMaker Studio
      - Notebook で探索
      - 実験管理
      ↓
    SageMaker Training
      - 分散トレーニング
      - ハイパーパラメータ調整
      ↓
    Model Registry
      - モデル登録
      - バージョン管理
  
  デプロイ:
    SageMaker Endpoint
      - リアルタイム推論
      - Auto Scaling
  
  監視:
    Model Monitor
      - データドリフト検出
      - モデル精度監視

メリット:
  - エンドツーエンド管理
  - 再現性の確保
  - スケーラブル
```

      Lambda
        - 結果集約
        - Redshift COPY

    S3（予測結果）

メリット:
  - コスト効率（リアルタイムより70%削減）

  - スケーラブル

## 実装例

### リアルタイム推論エンドポイント

```python
import boto3
import json

sagemaker = boto3.client('sagemaker')
runtime = boto3.client('sagemaker-runtime')

# モデル作成
model_response = sagemaker.create_model(
    ModelName='my-model',
    PrimaryContainer={
        'Image': '763104351884.dkr.ecr.ap-northeast-1.amazonaws.com/pytorch-inference:2.0-cpu',
        'ModelDataUrl': 's3://my-bucket/model/model.tar.gz',
        'Environment': {
            'SAGEMAKER_PROGRAM': 'inference.py',
            'SAGEMAKER_SUBMIT_DIRECTORY': 's3://my-bucket/code/sourcedir.tar.gz'
        }
    },
    ExecutionRoleArn='arn:aws:iam::123456789012:role/SageMakerRole'
)

# エンドポイント設定
endpoint_config = sagemaker.create_endpoint_config(
    EndpointConfigName='my-endpoint-config',
    ProductionVariants=[
        {
            'VariantName': 'AllTraffic',
            'ModelName': 'my-model',
            'InstanceType': 'ml.m5.xlarge',
            'InitialInstanceCount': 2,
            'InitialVariantWeight': 1.0
        }
    ]
)

# エンドポイント作成
endpoint = sagemaker.create_endpoint(
    EndpointName='my-endpoint',
    EndpointConfigName='my-endpoint-config'
)

# 推論実行
response = runtime.invoke_endpoint(
    EndpointName='my-endpoint',
    ContentType='application/json',
    Body=json.dumps({
        'instances': [
            {'features': [1.0, 2.0, 3.0, 4.0]}
        ]
    })
)

result = json.loads(response['Body'].read())
print(result)
```

### Auto Scaling設定

### SageMaker Pipelinesの構築

```python
from sagemaker.workflow.pipeline import Pipeline
from sagemaker.workflow.steps import ProcessingStep, TrainingStep
from sagemaker.workflow.parameters import ParameterString
from sagemaker.workflow.conditions import ConditionGreaterThanOrEqualTo
from sagemaker.workflow.condition_step import ConditionStep
from sagemaker.workflow.functions import JsonGet

# パラメータ定義
input_data = ParameterString(name="InputData", default_value="s3://my-bucket/data/")
accuracy_threshold = ParameterString(name="AccuracyThreshold", default_value="0.80")

# Processing Step
processing_step = ProcessingStep(
    name="PreprocessData",
    processor=sklearn_processor,
    inputs=[
        ProcessingInput(source=input_data, destination="/opt/ml/processing/input")
    ],
    outputs=[
        ProcessingOutput(output_name="train", source="/opt/ml/processing/train"),
        ProcessingOutput(output_name="validation", source="/opt/ml/processing/validation")
    ],
    code="preprocessing.py"
)

# Training Step
training_step = TrainingStep(
    name="TrainModel",
    estimator=xgboost_estimator,
    inputs={
        "train": TrainingInput(
            s3_data=processing_step.properties.ProcessingOutputConfig.Outputs["train"].S3Output.S3Uri
        ),
        "validation": TrainingInput(
            s3_data=processing_step.properties.ProcessingOutputConfig.Outputs["validation"].S3Output.S3Uri
        )
    }
)

# Condition Step（精度チェック）
cond_gte = ConditionGreaterThanOrEqualTo(
    left=JsonGet(
        step_name=training_step.name,
        property_file=evaluation_report,
        json_path="metrics.accuracy.value"
    ),
    right=accuracy_threshold
)

condition_step = ConditionStep(
    name="CheckAccuracy",
    conditions=[cond_gte],
    if_steps=[register_step],  # 精度OK → モデル登録
    else_steps=[fail_step]     # 精度NG → 失敗
)

# Pipeline作成
pipeline = Pipeline(
    name="MyMLPipeline",
    parameters=[input_data, accuracy_threshold],
    steps=[processing_step, training_step, condition_step]
)

pipeline.upsert(role_arn=role)
execution = pipeline.start()
```

### バッチ変換

```python
from sagemaker.transformer import Transformer

transformer = Transformer(
    model_name='my-model',
    instance_count=5,
    instance_type='ml.m5.xlarge',
    output_path='s3://my-bucket/batch-output/',
    strategy='MultiRecord',  # 複数レコード一括処理
    max_concurrent_transforms=10,
    max_payload=6,  # MB
    accept='application/json'
)

# バッチ変換実行
transformer.transform(
    data='s3://my-bucket/batch-input/',
    content_type='application/json',
    split_type='Line',
    join_source='Input',
    wait=True
)
```

## まとめ

**アーキテクチャ設計のポイント:**
- 用途に応じた推論オプション選択（リアルタイム/バッチ/サーバーレス）
- Pipelines で MLOps 実現
- Feature Store で特徴量管理
- Model Monitor で継続監視
- Auto Scaling で可用性・コスト最適化
- Multi-Model Endpoint でコスト削減
- スポットインスタンスでトレーニングコスト削減
- Step Functions でワークフローオーケストレーション
