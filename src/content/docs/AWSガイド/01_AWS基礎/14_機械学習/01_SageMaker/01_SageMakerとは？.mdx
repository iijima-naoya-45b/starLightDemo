## Amazon SageMaker とは？

SageMakerは、機械学習モデルの構築、トレーニング、デプロイを完全マネージドで提供するサービスです。

### 主要コンポーネント

#### 1. SageMaker Studio

```yaml
概要:
  - 統合開発環境（IDE）
  - Jupyter Notebook ベース
  - コラボレーション機能
  - ビジュアルインターフェース

機能:
  データ準備:
    - Data Wrangler（データ変換）
    - Feature Store（特徴量管理）
    - Processing Jobs（前処理）
  
  モデル開発:
    - Notebook インスタンス
    - コード補完
    - Git統合
    - デバッグ機能
  
  実験管理:
    - Experiments（実験追跡）
    - Model Registry（モデル管理）
    - バージョニング

統合サービス:
  - Amazon S3
  - AWS Glue
  - Amazon Athena
  - EMR
```

#### 2. SageMaker Autopilot

```yaml
概要:
  - AutoML（自動機械学習）
  - コーディング不要
  - 自動モデル選択
  - ハイパーパラメータ最適化

機能:
  データ分析:
    - 自動データ探索
    - 統計分析
    - 特徴量重要度
  
  モデル選択:
    - 複数アルゴリズム試行
    - 自動評価
    - 最適モデル選定
  
  説明可能性:
    - モデル解釈
    - 特徴量影響度
    - レポート生成

対応タスク:
  - 二値分類
  - 多クラス分類
  - 回帰
```

#### 3. SageMaker Training

```yaml
概要:
  - 分散トレーニング
  - マネージド環境
  - 自動スケーリング
  - スポットインスタンス対応

トレーニングオプション:
  組み込みアルゴリズム:
    - XGBoost
    - Linear Learner
    - DeepAR（時系列予測）
    - Object Detection
    - Image Classification
    - Seq2Seq
  
  カスタムアルゴリズム:
    - TensorFlow
    - PyTorch
    - MXNet
    - Scikit-learn
    - Dockerコンテナ

分散トレーニング:
  データ並列:
    - データ分割
    - 複数インスタンス
    - 勾配集約
  
  モデル並列:
    - 大規模モデル
    - レイヤー分割
    - Pipeline並列

スポットインスタンス:
  - 最大90%コスト削減
  - チェックポイント対応
  - 自動再開
```

#### 4. SageMaker Inference

```yaml
概要:
  - リアルタイム推論
  - バッチ推論
  - サーバーレス推論
  - 非同期推論

エンドポイント種類:
  リアルタイムエンドポイント:
    - 低レイテンシ（ミリ秒）
    - 常時起動
    - Auto Scaling対応
    - A/Bテスト可能
  
  サーバーレス推論:
    - オンデマンド
    - 自動スケーリング
    - コールドスタート許容
    - 従量課金
  
  バッチ変換:
    - 大量データ処理
    - S3入出力
    - 一括推論
    - コスト効率
  
  非同期推論:
    - 長時間処理
    - キューイング
    - S3ベース
    - コールバック対応

最適化:
  - マルチモデルエンドポイント
  - マルチコンテナエンドポイント
  - Elastic Inference
  - Neo（モデルコンパイル）
```

#### 5. SageMaker Data Wrangler

```yaml
概要:
  - ビジュアルデータ準備
  - ノーコード変換
  - 300以上の組み込み変換
  - データ品質分析

機能:
  データソース:
    - Amazon S3
    - Amazon Athena
    - Amazon Redshift
    - Snowflake
    - Databricks
  
  変換操作:
    - 欠損値処理
    - エンコーディング
    - スケーリング
    - 特徴量生成
    - フィルタリング
  
  分析:
    - データプロファイル
    - 相関分析
    - ターゲット漏洩検出
    - クイックモデル評価
  
  エクスポート:
    - Feature Store
    - S3
    - Processing Job
    - Pipeline統合
```

#### 6. SageMaker Feature Store

```yaml
概要:
  - 特徴量の一元管理
  - オンライン/オフライン ストア
  - バージョニング
  - メタデータ管理

機能:
  オンラインストア:
    - 低レイテンシ読み取り
    - リアルタイム推論用
    - ミリ秒レスポンス
  
  オフラインストア:
    - S3ベース
    - トレーニング用
    - バッチ処理
    - 時系列データ
  
  特徴量管理:
    - 特徴量グループ
    - スキーマ定義
    - バージョン管理
    - 系譜追跡

メリット:
  - 特徴量再利用
  - 一貫性確保
  - トレーニング/推論の整合性
  - チーム間共有
```

#### 7. SageMaker Pipelines

```yaml
概要:
  - MLパイプライン構築
  - CI/CD for ML
  - ワークフロー自動化
  - オーケストレーション

パイプラインステップ:
  - Processing（データ処理）
  - Training（トレーニング）
  - Tuning（ハイパーパラメータ調整）
  - Model Registration（モデル登録）
  - Condition（条件分岐）
  - Transform（バッチ変換）
  - Lambda（カスタム処理）

機能:
  - パラメータ化
  - 条件分岐
  - 並列実行
  - キャッシング
  - スケジュール実行
  - EventBridge統合

メリット:
  - 再現性
  - 自動化
  - バージョン管理
  - 監査証跡
```

#### 8. SageMaker Model Monitor

```yaml
概要:
  - モデル品質監視
  - データドリフト検出
  - アラート通知
  - 継続的監視

監視タイプ:
  データ品質:
    - 入力データ統計
    - スキーマ違反
    - 欠損値検出
  
  モデル品質:
    - 精度低下検出
    - Ground Truth比較
    - メトリクス追跡
  
  バイアス検出:
    - Clarify統合
    - 公平性監視
  
  特徴量ドリフト:
    - 分布変化検出
    - ベースライン比較

アラート:
  - CloudWatch Alarms
  - SNS通知
  - Lambda統合
  - 自動再トレーニング
```

### SageMaker vs 他サービス

```yaml
SageMaker vs EMR:
  SageMaker:
    - 機械学習特化
    - マネージド環境
    - モデル管理・デプロイ
    - 推論エンドポイント
    - AutoML
  
  EMR:
    - ビッグデータ処理
    - Spark/Hadoop
    - データ前処理
    - 大規模ETL
    - カスタマイズ可能

SageMaker vs AWS Glue:
  SageMaker:
    - ML パイプライン
    - モデルトレーニング
    - 特徴量エンジニアリング
    - モデルデプロイ
  
  Glue:
    - ETL処理
    - データカタログ
    - サーバーレスETL
    - データ統合

SageMaker vs Lambda:
  SageMaker:
    - 複雑なMLモデル
    - 大規模推論
    - GPU対応
    - モデル管理
  
  Lambda:
    - 軽量推論
    - イベント駆動
    - 短時間処理
    - サーバーレス

使い分け:
  - データ前処理: Glue / EMR
  - モデル開発・トレーニング: SageMaker
  - モデルデプロイ・推論: SageMaker
  - 軽量推論: Lambda
  - 大規模データ処理: EMR
```

### まとめ

**SageMakerの重要ポイント:**
- 完全マネージド機械学習プラットフォーム
- Studio でエンドツーエンド開発
- Autopilot で AutoML
- 分散トレーニング対応
- 複数の推論オプション（リアルタイム、バッチ、サーバーレス）
- Feature Store で特徴量管理
- Pipelines で MLOps 実現
- Model Monitor で継続的監視
- スポットインスタンスでコスト削減
