## Amazon DocumentDB (with MongoDB compatibility) とは？

Amazon DocumentDBは、MongoDB互換のマネージドドキュメントデータベースサービスです。JSONライクなドキュメントを格納し、スケーラブルで高性能なNoSQLデータベースを提供します。

### MongoDB互換性

```yaml
互換性:
  MongoDB API: 3.6, 4.0, 5.0
  ドライバ: MongoDB公式ドライバ対応
  移行: mongodump/mongorestore対応
  
サポート機能:
  - ドキュメントデータモデル
  - クエリ・インデックス
  - アグリゲーション
  - トランザクション（4.0以降）
  - Change Streams

制限事項:
  - シャーディング非対応
  - 一部の集約パイプライン未対応
  - GridFS非対応
```

### クラスター構成

```yaml
クラスター構成:
  プライマリインスタンス: 
    - 読み書き両方対応
    - 1つのみ
  
  レプリカインスタンス:
    - 読み取り専用
    - 最大15個
    - フェイルオーバー対応
  
ストレージ:
  - クラスター共有ストレージ
  - 自動拡張（10GB〜128TB）
  - 6コピー（3つのAZに分散）
  - 自動修復・バックアップ
```

### 主要機能

#### 1. 高可用性

```yaml
レプリケーション:
  - 3つのAZに6コピー
  - 自動フェイルオーバー（30秒以内）
  - 99.99%可用性SLA
  
フェイルオーバー:
  優先順位: Tier-0 → Tier-1 → ...
  接続エンドポイント: クラスターエンドポイント（自動切替）
  レプリカ昇格: 自動
```

#### 2. スケーラビリティ

```yaml
ストレージ:
  - 自動拡張
  - 最大128TB
  - ダウンタイムなし
  
コンピュート:
  - レプリカ追加（最大15個）
  - インスタンスクラス変更可能
  - 読み取りスケール
  
スループット:
  - 数百万リクエスト/秒
  - レプリカで負荷分散
```

#### 3. バックアップとリカバリ

```yaml
自動バックアップ:
  - 継続的バックアップ（クラスターボリューム）
  - ポイントインタイムリカバリ
  - 保持期間: 1-35日
  
スナップショット:
  - 手動スナップショット
  - クロスリージョンコピー対応
  - 別アカウント共有可能
  
リカバリ:
  - RPO: 5分
  - RTO: 数分〜数十分
```

#### 4. セキュリティ

```yaml
ネットワーク分離:
  - VPC内配置
  - セキュリティグループ
  - プライベートサブネット推奨
  
暗号化:
  保管時: KMS
  転送時: TLS 1.2
  
認証:
  - ユーザー名・パスワード
  - IAMデータベース認証
  - SCRAM認証（5.0以降）
```

```yaml
汎用（T3, T4g）:

汎用（R6g, R6i）:
  用途: 本番環境
  vCPU: 2-64
  メモリ: 16-512 GB
  価格: $0.278/時間〜

I/O最適化（R6gd, R6id）:
  用途: 高スループット要求
  vCPU: 2-64
  メモリ: 16-512 GB
  NVMe SSD: ローカルキャッシュ
```

### ストレージアーキテクチャ

```yaml
クラスター共有ストレージ:
  - SSDベース
  - 自動レプリケーション（6コピー）
  - 自動修復
  - 継続的バックアップ
  
特徴:
  - インスタンス障害時もデータ保持
  - ストレージとコンピュートの分離
  - 高速フェイルオーバー
  - 自動拡張
```

### エンドポイント

```yaml
クラスターエンドポイント:
  用途: 読み書き
  接続先: プライマリインスタンス
  フェイルオーバー: 自動切替
  例: mycluster.cluster-xxxxx.docdb.amazonaws.com

リーダーエンドポイント:
  用途: 読み取り専用
  接続先: レプリカ（ラウンドロビン）
  負荷分散: 自動
  例: mycluster.cluster-ro-xxxxx.docdb.amazonaws.com

インスタンスエンドポイント:
  用途: 特定インスタンス接続
  接続先: 個別インスタンス
  例: mycluster-instance-1.xxxxx.docdb.amazonaws.com
```

### DocumentDB vs MongoDB

```yaml
DocumentDB:
  ✓ フルマネージド
  ✓ 自動スケーリング
  ✓ 高可用性（99.99%）
  ✓ 自動バックアップ
  ✓ AWS統合
  × シャーディング非対応
  × 一部機能制限

MongoDB（self-managed）:
  ✓ 全機能利用可能
  ✓ 最新バージョン
  ✓ シャーディング
  × 運用負荷
  × 可用性設定必要
  × バックアップ管理

MongoDB Atlas（マネージド）:
  ✓ フルマネージド
  ✓ 全機能対応
  ✓ マルチクラウド
  × AWS統合限定的
  × 料金体系異なる
```

### まとめ

**DocumentDBの重要ポイント:**
- MongoDB互換のマネージドドキュメントDB
- 3つのAZに6コピーで高可用性
- 最大15個のレプリカで読み取りスケール
- 自動バックアップとポイントインタイムリカバリ
- JSONドキュメントモデル
- AWS統合（VPC、IAM、KMS、CloudWatch）
