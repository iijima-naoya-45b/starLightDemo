## Amazon ElastiCache とは？


**ポケモンで例えると**: AWSを理解することは、新しい「わざ」を覚えるようなもの——使いこなせば、より強力な開発者になれます。

ElastiCacheは、インメモリキャッシュサービスです。Redis/Memcachedをマネージドで提供します。

### エンジン

```yaml
Redis:
  - データ構造: String、List、Set、Hash等
  - 永続化: RDB、AOF
  - レプリケーション: あり
  - Pub/Sub: あり
  - トランザクション: あり
  - 推奨: ほとんどのケース

Memcached:
  - データ構造: Key-Value のみ
  - 永続化: なし
  - レプリケーション: なし
  - マルチスレッド: あり
  - 推奨: シンプルなキャッシュ
```

### Redisクラスターモード

```yaml
無効:
  - 1プライマリ + Read Replica最大5台
  - 単一シャード
  - 最大250GB
  - シンプル

有効:
  - 最大500シャード
  - 各シャード: 1プライマリ + Replica最大5台
  - 最大500ノード
  - 水平スケール
```

### 主要機能

```yaml
自動フェイルオーバー:
  - Multi-AZ
  - 自動検出・切替
  - ダウンタイム最小化

バックアップ:
  - 自動スナップショット
  - 手動スナップショット
  - S3保存

スケーリング:
  - 垂直: ノード種類変更
  - 水平: シャード追加（クラスターモード）
  - Read Replica追加
```

### Redis vs Memcached

```yaml
Redis:
  ☑ データ構造豊富
  ☑ 永続化
  ☑ レプリケーション
  ☑ Multi-AZ
  ☑ バックアップ
  ☒ シングルスレッド

Memcached:
  ☑ マルチスレッド
  ☑ シンプル
  ☒ 永続化なし
  ☒ レプリケーションなし
  ☒ バックアップなし
```

### まとめ

**ElastiCacheの重要ポイント:**
- インメモリキャッシュ
- Redis推奨（機能豊富）
- Multi-AZ、自動フェイルオーバー
- クラスターモードで水平スケール
- DB負荷削減、パフォーマンス向上
