## RDS ユースケースおよびアーキテクチャパターン

### 1. 高可用性Webアプリ

```yaml
構成:
  ALB → EC2 → RDS Multi-AZ
  
RDS設定:
  エンジン: MySQL 8.0
  インスタンス: db.m6i.large
  Multi-AZ: 有効
  自動バックアップ: 7日保持
  
メリット:
  - 自動フェイルオーバー（60秒）
  - AZ障害対応
  - メンテナンス時の可用性
```

### 2. 読み取りスケール

```yaml
構成:
  Primary（書き込み）
  Read Replica ×3（読み取り）
  
用途:
  - レポート生成: Replica1
  - 分析処理: Replica2
  - 検索機能: Replica3
  
負荷分散:
  - Route 53加重ルーティング
  - アプリケーション側で制御
```

### 3. クロスリージョンDR

```yaml
Primary: ap-northeast-1
  Multi-AZ: 有効
  
Read Replica: us-east-1
  クロスリージョンレプリケーション
  プロモーション可能
  
RPO: 数秒〜数分
RTO: 数分（手動プロモーション）
```

### 4. 開発/本番分離

```yaml
本番環境:
  - Multi-AZ
  - db.m6i.large
  - 自動バックアップ: 14日
  
開発環境:
  - Single-AZ
  - db.t3.medium
  - スナップショットから復元
  - 自動停止（夜間・週末）
```
