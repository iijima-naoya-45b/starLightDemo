## Amazon RDS (Relational Database Service) とは？

Amazon RDSは、マネージド型リレーショナルデータベースサービスです。データベースの運用管理を自動化し、開発者はアプリケーション開発に集中できます。

### 対応データベースエンジン

```yaml
MySQL:
  バージョン: 5.7, 8.0
  用途: Webアプリ、中小規模
  
PostgreSQL:
  バージョン: 12, 13, 14, 15, 16
  用途: エンタープライズ、GIS
  
MariaDB:
  バージョン: 10.6, 10.11
  用途: MySQL互換
  
Oracle:
  エディション: SE, EE, SE2
  ライセンス: BYOL, LI
  
SQL Server:
  エディション: Express, Web, Standard, Enterprise
  ライセンス: LI
  
Aurora MySQL/PostgreSQL:
  互換性: MySQL 5.7/8.0, PostgreSQL 13-16
  性能: 5倍(MySQL), 3倍(PostgreSQL)
```

### RDSの主要機能

#### 1. 自動バックアップ

```yaml
特徴:
  - 自動日次バックアップ
  - トランザクションログ継続保存
  - ポイントインタイムリカバリ
  - 保持期間: 0-35日

設定:
  バックアップウィンドウ: 深夜推奨
  保持期間: 7日（デフォルト）
  暗号化: KMS
```

#### 2. Multi-AZ配置

```yaml
特徴:
  - 同期レプリケーション
  - 自動フェイルオーバー（60-120秒）
  - AZ障害対応
  - メンテナンス時の高可用性

構成:
  Primary: AZ-1a
  Standby: AZ-1c（同期レプリケーション）
  
フェイルオーバートリガー:
  - AZ障害
  - プライマリDB障害
  - インスタンスクラス変更
  - OSパッチ適用
```

#### 3. Read Replica

```yaml
特徴:
  - 非同期レプリケーション
  - 読み取り負荷分散
  - 最大15個（Aurora: 15個）
  - クロスリージョン対応

用途:
  - レポート生成
  - 分析処理
  - 災害対策

プロモーション:
  - Read ReplicaをPrimaryに昇格可能
  - RPO: 数秒〜数分
```

#### 4. 自動スケーリング

```yaml
Storage Auto Scaling:
  - ストレージ自動拡張
  - ダウンタイムなし
  - 最大容量設定

Compute:
  - インスタンスクラス変更
  - ダウンタイム発生（数分）
```

### インスタンスクラス

```yaml
汎用（T3, T4g）:
  用途: 開発、テスト、小規模本番
  CPU: 2-8 vCPU
  メモリ: 1-32 GB
  価格: $0.017/時間〜

汎用（M6i, M6g）:
  用途: 本番環境
  CPU: 2-128 vCPU
  メモリ: 8-512 GB
  価格: $0.096/時間〜

メモリ最適化（R6i, R6g, X2iedn）:
  用途: 大規模DB、高負荷
  CPU: 2-128 vCPU
  メモリ: 16-4096 GB
  価格: $0.126/時間〜
```

### ストレージ

```yaml
gp3（汎用SSD - 推奨）:
  IOPS: 3,000-16,000
  スループット: 125-1,000 MB/s
  価格: $0.115/GB/月

gp2（汎用SSD）:
  IOPS: 100-16,000（サイズ連動）
  価格: $0.115/GB/月

io1（プロビジョンドIOPS）:
  IOPS: 最大64,000
  用途: 高IOPS要求DB
  価格: $0.125/GB/月 + IOPS料金

Magnetic（非推奨）:
  レガシー
```

### セキュリティ

```yaml
ネットワーク分離:
  - VPC内配置
  - セキュリティグループ
  - プライベートサブネット推奨

暗号化:
  保管時: KMS
  転送時: SSL/TLS
  
認証:
  - データベースユーザー
  - IAMデータベース認証
```

### まとめ

**RDSの重要ポイント:**
- マネージド型で運用負荷軽減
- Multi-AZで高可用性
- Read Replicaで読み取りスケール
- 自動バックアップとポイントインタイムリカバリ
- 暗号化によるセキュリティ強化
