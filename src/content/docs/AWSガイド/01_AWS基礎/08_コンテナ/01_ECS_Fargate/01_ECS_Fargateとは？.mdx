## Amazon ECS/Fargate とは？

ECSは、コンテナオーケストレーションサービスです。Fargateはサーバーレスコンテナ実行環境です。

### 起動タイプ

```yaml
EC2起動タイプ:
  - EC2インスタンス管理必要
  - 柔軟な設定
  - コスト効率（大規模）
  - AMI、パッチ管理必要

Fargate起動タイプ（推奨）:
  - サーバーレス
  - インフラ管理不要
  - タスク単位課金
  - 推奨: ほとんどのケース
```

### 基本概念

```yaml
クラスター:
  - タスク/サービスのグループ
  - VPC内に配置

タスク定義:
  - コンテナ設定のテンプレート
  - イメージ、CPU、メモリ、環境変数

タスク:
  - タスク定義から起動されたインスタンス
  - 1つ以上のコンテナ

サービス:
  - タスクの長期実行・管理
  - Auto Scaling
  - ロードバランサー統合
```

### ネットワークモード

```yaml
awsvpc（Fargate必須）:
  - タスク専用ENI
  - セキュリティグループ
  - プライベートIP

bridge（EC2のみ）:
  - ホストのDockerブリッジ
  - ポートマッピング

host（EC2のみ）:
  - ホストネットワーク直接使用
```

### サービス検出

```yaml
AWS Cloud Map統合:
  - DNS自動登録
  - ヘルスチェック
  - サービスメッシュ

Route 53統合:
  - Private Hosted Zone
  - 自動DNS更新
```

### Auto Scaling

```yaml
タスク数スケーリング:
  - ターゲット追跡
  - ステップスケーリング
  - スケジュール

メトリクス:
  - CPU使用率
  - メモリ使用率
  - ALBリクエスト数
  - カスタムメトリクス
```

| リソース | 価格 | 備考 |

#### EC2起動タイプ料金

| 項目 | 価格 | 備考 |
|---|---|---|
| **ECS自体** | 無料 | コントロールプレーン不要 |
| **EC2インスタンス** | 標準料金 | オンデマンド/Spot/リザーブド |

**Fargate vs EC2 コスト比較（月間、10タスク常時稼働）:**

| 起動タイプ | 構成 | 月額料金 |
|---|---|---|
| Fargate | 1 vCPU、2GB × 10 | $355.50 |
| EC2 | t3.medium × 5（各2タスク） | $149.76（オンデマンド）<br />$68.90（Spot平均） |

**選択基準:**
- **Fargate**: 小規模、運用簡単、サーバーレス
- **EC2**: 大規模、コスト重視、高度な制御

### まとめ

**ECS/Fargateの重要ポイント:**
- ECS: コンテナオーケストレーション
- Fargate: サーバーレス（推奨）
- EC2起動タイプ: 大規模でコスト効率
- タスク定義で設定、サービスで管理
- ALB統合、Auto Scaling対応
