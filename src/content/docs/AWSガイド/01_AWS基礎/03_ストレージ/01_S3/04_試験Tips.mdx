## S3 試験Tips (SAA/SAP)

### 頻出トピック

#### 1. ストレージクラス選択

```yaml
頻出問題パターン:

Q: 頻繁アクセス、高可用性必要
A: S3 Standard

Q: 月1回アクセス、コスト削減
A: S3 Standard-IA

Q: 年1回アクセス、即時取得必要
A: S3 Glacier Instant Retrieval

Q: 7年保管、取得頻度極低
A: S3 Glacier Deep Archive

Q: アクセスパターン不明
A: S3 Intelligent-Tiering
```

#### 2. データ保護

```yaml
バージョニング:
  - 誤削除防止
  - ロールバック可能
  - MFA削除で強化

クロスリージョンレプリケーション:
  - 災害対策
  - レイテンシー削減
  - コンプライアンス

S3 Object Lock:
  - WORM（Write Once Read Many）
  - コンプライアンス対応
  - 期間指定保持
```

#### 3. パフォーマンス最適化

```yaml
Transfer Acceleration:
  - グローバルアップロード高速化
  - CloudFrontエッジ経由
  - 50倍高速化可能

マルチパートアップロード:
  - 100MB以上推奨
  - 並列アップロード
  - 失敗時部分再送

S3 Select:
  - オブジェクト内部フィルタ
  - データ転送量削減
  - コスト削減
```

### 頻出シナリオ問題

#### シナリオ1: コスト最適化

```
要件:
- ログファイル保存
- 30日間頻繁アクセス
- その後アーカイブ
- 1年後削除

解答:
ライフサイクルポリシー:
  - 0-30日: S3 Standard
  - 30-365日: S3 Glacier
  - 365日後: 削除

ポイント:
✓ 自動階層化
✓ コスト最小化
✓ 管理不要
```

#### シナリオ2: 災害対策

```
要件:
- クリティカルデータ
- リージョン障害対応
- 低RPO/RTO

解答:
- バージョニング有効化
- クロスリージョンレプリケーション
- S3 Object Lock（オプション）

RPO: ほぼ0
RTO: 即座
```

### よくある間違い

```yaml
× 誤り: 全データS3 Standard保存
○ 正解: ライフサイクルポリシーで自動階層化

× 誤り: バケットポリシーなしでパブリック公開
○ 正解: 適切なバケットポリシー設定

× 誤り: 暗号化なし
○ 正解: 最低でもSSE-S3有効化
```
