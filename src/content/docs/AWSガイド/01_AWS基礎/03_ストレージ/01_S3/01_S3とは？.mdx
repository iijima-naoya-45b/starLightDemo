## Amazon S3 (Simple Storage Service) とは？

Amazon S3は、オブジェクトストレージサービスで、スケーラブルで耐久性の高いデータ保存を提供します。

### 基本概念

```yaml
特徴:
  - 無制限のストレージ容量
  - 99.999999999% (11 9's) の耐久性
  - 99.99%の可用性
  - オブジェクトサイズ: 0B 〜 5TB

主要概念:
  バケット:
    - グローバルに一意な名前
    - リージョン単位で作成
    - オブジェクトのコンテナ
  
  オブジェクト:
    - キー（ファイル名）
    - データ（ファイル内容）
    - メタデータ
    - バージョンID
```

### ストレージクラス

#### 1. 頻繁なアクセス

```yaml
S3 Standard:
  用途: アクティブデータ
  可用性: 99.99%
  取得料金: なし
  最小保存期間: なし
  価格: $0.023/GB/月

S3 Intelligent-Tiering:
  用途: アクセスパターン不明
  特徴: 自動階層化
  可用性: 99.9%
  価格: $0.0025/1000オブジェクト + ストレージ料金
```

#### 2. 低頻度アクセス

```yaml
S3 Standard-IA:
  用途: バックアップ、災害対策
  可用性: 99.9%
  取得料金: $0.01/GB
  最小保存期間: 30日
  価格: $0.0125/GB/月

S3 One Zone-IA:
  用途: 再作成可能データ
  可用性: 99.5%（単一AZ）
  取得料金: $0.01/GB
  最小保存期間: 30日
  価格: $0.01/GB/月
```

#### 3. アーカイブ

```yaml
S3 Glacier Instant Retrieval:
  用途: アーカイブ、即時アクセス必要
  取得時間: ミリ秒
  最小保存期間: 90日
  価格: $0.004/GB/月

S3 Glacier Flexible Retrieval:
  用途: アーカイブ、数時間待機可能
  取得時間: 1-5分 〜 12時間
  最小保存期間: 90日
  価格: $0.0036/GB/月

S3 Glacier Deep Archive:
  用途: 長期アーカイブ
  取得時間: 12 〜 48時間
  最小保存期間: 180日
  価格: $0.00099/GB/月
```

### バージョニング

```yaml
特徴:
  - オブジェクトの全バージョン保持
  - 誤削除防止
  - ロールバック可能

有効化:
  - バケット単位で設定
  - 一度有効化すると無効化不可（中断のみ）

削除マーカー:
  - 削除時、削除マーカー追加
  - 実データは保持
  - 削除マーカー削除で復元
```

### ライフサイクルポリシー

```yaml
自動移行:
  ルール1:
    - 30日後: Standard → Standard-IA
    - 90日後: Standard-IA → Glacier
    - 365日後: 削除
  
  ルール2（バージョン管理）:
    - 現在バージョン: 上記と同じ
    - 旧バージョン: 7日後削除

コスト削減:
  - 自動階層化
  - 古いデータ自動削除
  - アクセスパターン最適化
```

### セキュリティ

#### 1. アクセス制御

```yaml
バケットポリシー:
  - JSONベース
  - バケット全体に適用
  - パブリックアクセス可能

IAMポリシー:
  - ユーザー/ロール単位
  - プライベートアクセス

ACL:
  - レガシー
  - 非推奨
```

#### 2. 暗号化

```yaml
サーバー側暗号化:
  SSE-S3:
    - S3管理キー
    - デフォルト
    - 無料
  
  SSE-KMS:
    - AWS KMS管理キー
    - 監査可能
    - 追加料金
  
  SSE-C:
    - 顧客管理キー
    - 完全制御

クライアント側暗号化:
  - アップロード前に暗号化
  - 完全なデータ制御
```

### データ転送

```yaml
Transfer Acceleration:
  - CloudFront エッジロケーション経由
  - 最大50倍高速化
  - 追加料金: $0.04/GB

S3 バッチオペレーション:
  - 大量オブジェクト一括処理
  - コピー、タグ付け、暗号化等
  
マルチパートアップロード:
  - 100MB以上推奨
  - 最大5TBサポート
  - 並列アップロード
```

### まとめ

**S3の重要ポイント:**
- ストレージクラス適切な選択
- ライフサイクルポリシーによるコスト最適化
- バージョニングによるデータ保護
- 暗号化によるセキュリティ強化
- Transfer Accelerationによる高速化
