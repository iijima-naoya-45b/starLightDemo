## Amazon EFS (Elastic File System) とは？

Amazon EFSは、マネージド型のNFSv4ファイルシステムで、複数のEC2インスタンスから同時アクセス可能な共有ファイルストレージを提供します。

### 基本概念

```yaml
特徴:
  - 完全マネージド型NFSファイルシステム
  - 複数のEC2インスタンスから同時マウント可能
  - 複数のAZにまたがる耐久性
  - 自動スケーリング（容量無制限）
  - 99.99%の可用性SLA

主要概念:
  ファイルシステム:
    - NFSv4/4.1プロトコル
    - POSIX準拠
    - リージョン内の複数AZに自動レプリケーション
  
  マウントターゲット:
    - 各AZに作成
    - ENI（Elastic Network Interface）
    - セキュリティグループで制御
  
  アクセスポイント:
    - アプリケーション固有のエントリーポイント
    - ユーザー・グループID強制
    - ルートディレクトリ指定
```

### ストレージクラス

#### 1. EFS Standard

```yaml
特徴:
  - マルチAZ冗長化
  - 最も高い可用性・耐久性
  - 頻繁にアクセスされるファイル向け

料金（東京リージョン）:
  - ストレージ: $0.30/GB/月
  - データアクセス: なし
```

#### 2. EFS Standard-IA (Infrequent Access)

```yaml
特徴:
  - マルチAZ冗長化
  - 低頻度アクセスファイル向け
  - 自動ライフサイクル管理

料金（東京リージョン）:
  - ストレージ: $0.019/GB/月
  - データアクセス: $0.01/GB読み取り
  
最小保存期間:
  - なし（S3-IAと異なる）
```

#### 3. EFS One Zone

```yaml
特徴:
  - 単一AZ（選択可能）
  - コスト削減重視
  - 開発・テスト環境向け

料金（東京リージョン）:
  - ストレージ: $0.19/GB/月
  - データアクセス: なし
```

#### 4. EFS One Zone-IA

```yaml
特徴:
  - 単一AZ
  - 最も低コスト
  - 非クリティカルデータ

料金（東京リージョン）:
  - ストレージ: $0.012/GB/月
  - データアクセス: $0.01/GB読み取り
```

**ストレージクラス比較:**

| クラス | 可用性 | 冗長化 | ストレージ料金 | アクセス料金 | 用途 |
|---|---|---|---|---|---|
| **Standard** | 99.99% | マルチAZ | $0.30/GB | なし | 本番アクティブデータ |
| **Standard-IA** | 99.99% | マルチAZ | $0.019/GB | $0.01/GB | 低頻度アクセス |
| **One Zone** | 99.9% | 単一AZ | $0.19/GB | なし | 開発・テスト |
| **One Zone-IA** | 99.9% | 単一AZ | $0.012/GB | $0.01/GB | 非クリティカル |

### パフォーマンスモード

#### 1. General Purpose（汎用）

```yaml
特徴:
  - レイテンシー重視
  - 一般的なワークロード向け
  - デフォルト設定

制限:
  - ファイル操作レイテンシー: 1桁ミリ秒
  - 同時接続: 7,000まで推奨

用途:
  - Webサーバー
  - コンテンツ管理
  - ホームディレクトリ
```

#### 2. Max I/O（最大スループット）

```yaml
特徴:
  - スループット重視
  - 高並列ワークロード向け
  - レイテンシーは高め

制限:
  - ファイル操作レイテンシー: 2桁ミリ秒
  - 同時接続: ほぼ無制限

用途:
  - ビッグデータ分析
  - メディアレンダリング
  - ゲノム解析
```

**パフォーマンスモードの選択:**
- 不明な場合: **General Purpose**（後から変更不可のため注意）
- 数千以上の同時接続: **Max I/O**

### スループットモード

#### 1. Bursting（バースト）

```yaml
特徴:
  - ストレージ量に応じたスループット
  - バーストクレジット制
  - デフォルト設定

スループット:
  - ベースライン: 50 MB/s per TB
  - バースト: 最大100 MB/s
  - 最小保証: 1 MB/s

計算例:
  - 100 GB → 5 MB/s（ベースライン）
  - 1 TB → 50 MB/s（ベースライン）+ 100 MB/sバースト
  - 10 TB → 500 MB/s（ベースライン）+ 100 MB/sバースト
```

#### 2. Provisioned（プロビジョニング）

```yaml
特徴:
  - 固定スループット保証
  - ストレージ量に依存しない
  - 追加料金発生

設定:
  - 1 MB/s 〜 1024 MB/s
  - 料金: $6/MB/s/月

用途:
  - 小容量で高スループット必要
  - 安定したパフォーマンス必須
```

#### 3. Elastic（エラスティック）

```yaml
特徴:
  - 自動スケーリング
  - 最もシンプル
  - 推奨モード（新規デフォルト）

スループット:
  - 読み取り: 最大3 GB/s
  - 書き込み: 最大1 GB/s
  - 自動調整

料金:
  - 読み取り: $0.03/GB
  - 書き込み: $0.06/GB
```

### ライフサイクル管理

```yaml
自動階層化:
  設定オプション:
    - 7日間アクセスなし → IA移行
    - 14日間アクセスなし → IA移行
    - 30日間アクセスなし → IA移行
    - 60日間アクセスなし → IA移行
    - 90日間アクセスなし → IA移行

  アクセス時:
    - 自動的にStandardに戻る
    - 透過的な動作

コスト削減効果:
  - 最大92%削減可能
  - 自動管理・運用不要
```

### セキュリティ

#### 1. アクセス制御

```yaml
セキュリティグループ:
  - マウントターゲットに適用
  - NFSポート（2049）制御
  - 基本的な制御

IAMポリシー:
  - ファイルシステムレベル制御
  - API操作制御
  - アクセスポイント統合

POSIX権限:
  - ファイル/ディレクトリレベル
  - UID/GID
  - chmod/chown
```

#### 2. 暗号化

```yaml
保管時の暗号化:
  - AWS KMS統合
  - ファイルシステム作成時設定
  - 後から有効化不可

転送時の暗号化:
  - TLS 1.2
  - EFSマウントヘルパー使用
  - 推奨設定
```

### バックアップ

```yaml
AWS Backup統合:
  - 自動バックアップ
  - ポイントインタイムリストア
  - クロスリージョンコピー

料金:
  - $0.05/GB/月
  - リストア: $0.02/GB
```

### EFS vs EBS vs S3

| 特徴 | EFS | EBS | S3 |
|---|---|---|---|
| **タイプ** | ファイルストレージ | ブロックストレージ | オブジェクトストレージ |
| **プロトコル** | NFS | iSCSI相当 | HTTP/S |
| **同時アクセス** | 数千インスタンス | 1インスタンス（io2のみ最大16） | 無制限 |
| **可用性** | マルチAZ | 単一AZ | マルチAZ |
| **スケーリング** | 自動（ペタバイト） | 手動（64TB） | 自動（無制限） |
| **料金** | $0.30/GB/月 | $0.12/GB/月（gp3） | $0.023/GB/月 |
| **用途** | 共有ファイル | OS・DB | バックアップ・静的コンテンツ |

### まとめ

**EFSの重要ポイント:**
- NFSプロトコルによる共有ファイルシステム
- 複数EC2インスタンスから同時マウント可能
- マルチAZ自動レプリケーション
- ライフサイクル管理によるコスト最適化
- Elastic スループットモードが推奨
- セキュリティグループ + IAM + POSIX権限の多層制御
