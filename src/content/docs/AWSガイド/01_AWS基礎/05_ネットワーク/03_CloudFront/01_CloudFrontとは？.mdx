## Amazon CloudFront とは？

CloudFrontは、グローバルCDN（Content Delivery Network）サービスです。世界中のエッジロケーションからコンテンツを高速配信します。

### 基本概念

```yaml
エッジロケーション:
  - 世界450以上の拠点
  - コンテンツキャッシュ
  - ユーザーに最も近い拠点から配信

オリジン:
  - S3バケット
  - ALB/NLB
  - EC2
  - カスタムHTTPサーバー

ディストリビューション:
  - Web: HTTP/HTTPS
  - RTMP: メディアストリーミング（非推奨）
```

### 主要機能

#### 1. キャッシュ

```yaml
キャッシュ動作:
  - TTL設定（秒単位）
  - ヘッダーベースキャッシュ
  - クエリ文字列キャッシュ
  - Cookieベースキャッシュ

キャッシュ無効化:
  - Invalidation（最大3,000パス/月無料）
  - バージョニング（推奨）
```

#### 2. セキュリティ

```yaml
HTTPS:
  - AWS証明書（ACM）無料
  - カスタム証明書
  - HTTP → HTTPS リダイレクト

Signed URL/Cookie:
  - プライベートコンテンツ
  - 有効期限設定
  - アクセス制御

AWS WAF統合:
  - DDoS保護
  - SQL injection対策
  - 地理的制限
```

#### 3. Lambda@Edge

```yaml
機能:
  - リクエスト/レスポンス変更
  - A/Bテスト
  - 認証/認可
  - SEO最適化

実行タイミング:
  - Viewer Request
  - Origin Request
  - Origin Response
  - Viewer Response
```

#### 4. Origin Failover

```yaml
構成:
  Primary Origin: us-east-1 ALB
  Secondary Origin: ap-northeast-1 ALB
  
動作:
  - Primary障害時に自動切替
  - ステータスコードベース（5xx）
```

### まとめ

**CloudFrontの重要ポイント:**
- グローバルCDN、低レイテンシー
- S3、ALB等をオリジンに設定
- HTTPS対応、WAF統合
- Lambda@Edgeでエッジ処理
- キャッシュでコスト削減
