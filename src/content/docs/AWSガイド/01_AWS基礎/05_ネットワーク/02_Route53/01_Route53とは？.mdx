## Amazon Route 53 とは？


**ポケモンで例えると**: AWSを理解することは、新しい「わざ」を覚えるようなもの——使いこなせば、より強力な開発者になれます。

Route 53は、高可用性でスケーラブルなDNSサービスです。ドメイン登録、DNSルーティング、ヘルスチェック機能を提供します。

### 主要機能

#### 1. DNSルーティングポリシー

```yaml
シンプルルーティング:
  - 単一リソース
  - 複数IPアドレス（ランダム返却）

加重ルーティング:
  - トラフィック比率制御
  - 例: 80% → ALB1, 20% → ALB2
  - A/Bテスト、Blue/Greenデプロイ

レイテンシーベースルーティング:
  - 最も低レイテンシーのリージョンへルーティング
  - グローバル展開

フェイルオーバー:
  - プライマリ/セカンダリ構成
  - ヘルスチェック連動
  - DR対応

地理的位置ルーティング:
  - ユーザーの地理的位置ベース
  - 例: 日本 → ap-northeast-1
  
地理的近接性ルーティング:
  - 地理的近接性 + バイアス設定
  - トラフィック調整可能

複数値回答ルーティング:
  - 最大8つのヘルシーなレコード返却
  - 簡易的な負荷分散
```

#### 2. ヘルスチェック

```yaml
エンドポイントヘルスチェック:
  - IPアドレス/ドメイン監視
  - プロトコル: HTTP, HTTPS, TCP
  - 間隔: 30秒（標準）、10秒（高速）
  - 判定: 複数ヘルスチェッカーからの結果

計算ヘルスチェック:
  - 複数ヘルスチェックの組み合わせ
  - AND/OR/NOT

CloudWatch Alarmヘルスチェック:
  - CloudWatchアラーム連動
```

#### 3. ドメイン登録

```yaml
機能:
  - ドメイン名登録
  - ドメイン移管
  - 自動更新
  
TLD対応:
  - .com, .net, .org
  - .jp, .co.jp
  - 100以上のTLD
```

### レコード種類

```yaml
A: IPv4アドレス
AAAA: IPv6アドレス
CNAME: 別名（ゾーン頂点不可）
Alias: AWS リソースへの別名（推奨）
  - ゾーン頂点対応
  - ヘルスチェック対応
  - 無料
MX: メールサーバー
TXT: テキスト情報
NS: ネームサーバー
SOA: ゾーン情報
```

### まとめ

**Route 53の重要ポイント:**
- 高可用性DNS（100% SLA）
- 多様なルーティングポリシー
- ヘルスチェックによる自動フェイルオーバー
- Aliasレコードでコスト削減
- グローバル展開に最適
