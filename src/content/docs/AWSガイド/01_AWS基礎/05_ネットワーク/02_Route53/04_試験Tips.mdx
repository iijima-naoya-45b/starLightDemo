## Route 53 試験Tips (SAA/SAP)

### 頻出トピック

#### 1. Alias vs CNAME

```yaml
Alias（推奨）:
  - AWS リソース専用
  - ゾーン頂点対応（example.com）
  - ヘルスチェック対応
  - クエリ無料
  - 対象: ALB, CloudFront, S3, API Gateway等

CNAME:
  - 任意ドメイン
  - ゾーン頂点不可（×example.com）
  - ヘルスチェック不可
  - クエリ課金
  - サブドメインのみ（www.example.com）

頻出:
  Q: example.com → ALB
  A: Aliasレコード（×CNAMEは不可）
```

#### 2. ルーティングポリシー選択

```yaml
シンプル: 単一リソース
加重: トラフィック比率制御（A/Bテスト）
レイテンシー: 最低レイテンシーリージョン
フェイルオーバー: DR、自動切替
地理的位置: ユーザー位置ベース
複数値回答: 簡易負荷分散
```

#### 3. ヘルスチェック

```yaml
必須暗記:
  - エンドポイント監視
  - 計算ヘルスチェック（AND/OR）
  - CloudWatch Alarm連動
  - フェイルオーバーと組み合わせ
```

### 頻出シナリオ

#### シナリオ1: DR対策

```
要件: プライマリ障害時に自動フェイルオーバー
解答: フェイルオーバールーティング + ヘルスチェック

構成:
  Primary: ap-northeast-1
  Secondary: us-east-1
  ヘルスチェック: Primary監視
```

#### シナリオ2: グローバル展開

```
要件: 各リージョンで最低レイテンシー
解答: レイテンシーベースルーティング

ポイント:
✓ 自動最適リージョン選択
✓ ヘルスチェック連動
✓ リージョン障害時自動切替
```

#### シナリオ3: Blue/Green

```
要件: 段階的デプロイ、即座にロールバック可能
解答: 加重ルーティング

手順:
  1. 90% Blue, 10% Green
  2. 検証OK → 50/50
  3. 完全移行 → 0/100
```

### よくある間違い

```yaml
× 誤り: ゾーン頂点にCNAME
○ 正解: ゾーン頂点にはAliasレコード

× 誤り: ヘルスチェックなしでフェイルオーバー
○ 正解: ヘルスチェック必須

× 誤り: 非AWSリソースにAlias
○ 正解: 非AWSはCNAME、AWSはAlias
```
