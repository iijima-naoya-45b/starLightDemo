## AWS CloudFormation とは？

CloudFormationは、Infrastructure as Code（IaC）サービスです。テンプレートでAWSリソースを宣言的に定義・管理します。

### 基本概念

```yaml
テンプレート:
  - JSON/YAML形式
  - リソース定義
  - パラメータ、出力

スタック:
  - テンプレートから作成されたリソース群
  - 一括管理
  - 一括削除

変更セット:
  - 更新プレビュー
  - 影響確認
  - 安全な更新
```

### テンプレート構造

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: 説明

Parameters:
  # 入力パラメータ

Resources:
  # リソース定義（必須）

Outputs:
  # 出力値

Conditions:
  # 条件分岐

Mappings:
  # マッピング
```

### 主要機能

```yaml
スタック管理:
  - 作成、更新、削除
  - ロールバック
  - ドリフト検出

ネステッドスタック:
  - スタック分割
  - 再利用

クロススタック参照:
  - Export/ImportValue
  - スタック間連携

StackSets:
  - マルチアカウント
  - マルチリージョン
```

### 組み込み関数

```yaml
Ref: リソース参照
Fn::GetAtt: 属性取得
Fn::Sub: 文字列置換
Fn::Join: 結合
Fn::Select: 選択
Fn::If: 条件分岐
```

### 料金

**CloudFormation本体は無料です**

| 項目 | 価格 | 備考 |
|---|---|---|
| **CloudFormation使用料** | 無料 | テンプレート作成・スタック管理 |
| **作成されたAWSリソース** | 各サービスの標準料金 | EC2、S3等の料金 |
| **API呼び出し** | ごく少額 | 通常無視できるレベル |

**料金例（CloudFormationで作成したリソース）:**

| リソース | 月額料金例 | 備考 |
|---|---|---|
| EC2 t3.medium × 2 | $59.90 | インスタンス料金 |
| ALB | $73.80 | ロードバランサー料金 |
| RDS db.t3.medium | $97.92 | データベース料金 |
| S3 100GB | $2.30 | ストレージ料金 |
| **合計** | **$233.92/月** | CloudFormation料金は$0 |

**コストメリット:**
- CloudFormation自体は完全無料
- リソースの作成・削除が簡単で、不要なリソースをすぐ削除できるため結果的にコスト削減
- 環境の複製が容易で、本番/開発環境の使い分けが可能

### まとめ

**CloudFormationの重要ポイント:**
- Infrastructure as Code
- 宣言的定義
- バージョン管理可能
- スタック一括管理
- 変更セットで安全更新
