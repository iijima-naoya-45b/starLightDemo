## AWS CloudFormation とは？

CloudFormationは、Infrastructure as Code（IaC）サービスです。テンプレートでAWSリソースを宣言的に定義・管理します。

### 基本概念

```yaml
テンプレート:
  - JSON/YAML形式
  - リソース定義
  - パラメータ、出力

スタック:
  - テンプレートから作成されたリソース群
  - 一括管理
  - 一括削除

変更セット:
  - 更新プレビュー
  - 影響確認
  - 安全な更新
```

### テンプレート構造

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: 説明

Parameters:
  # 入力パラメータ

Resources:
  # リソース定義（必須）

Outputs:
  # 出力値

Conditions:
  # 条件分岐

Mappings:
  # マッピング
```

### 主要機能

```yaml
スタック管理:
  - 作成、更新、削除
  - ロールバック
  - ドリフト検出

ネステッドスタック:
  - スタック分割
  - 再利用

クロススタック参照:
  - Export/ImportValue
  - スタック間連携

StackSets:
  - マルチアカウント
  - マルチリージョン
```

### 組み込み関数

```yaml
Ref: リソース参照
Fn::GetAtt: 属性取得
Fn::Sub: 文字列置換
Fn::Join: 結合
Fn::Select: 選択
Fn::If: 条件分岐
```

### 料金

```yaml
CloudFormation自体: 無料

課金対象:
  - 作成されたAWSリソース
  - API呼び出し（ごく少額）
```

### まとめ

**CloudFormationの重要ポイント:**
- Infrastructure as Code
- 宣言的定義
- バージョン管理可能
- スタック一括管理
- 変更セットで安全更新
