## Systems Manager ユースケースおよびアーキテクチャパターン

### 1. セキュアなリモートアクセス

```yaml
構成:
  管理者 → Session Manager → EC2（Private Subnet）

メリット:
  - Bastion不要
  - SSH鍵不要
  - 監査ログ自動
```

### 2. 一括パッチ適用

```yaml
構成:
  Patch Manager → Run Command → EC2群

スケジュール:
  - 毎月第2火曜日
  - メンテナンスウィンドウ
  - 段階的適用

通知: SNS
```

### 3. 設定管理

```yaml
構成:
  アプリ → Parameter Store → 設定値取得

階層例:
  /myapp/prod/db-host
  /myapp/prod/db-password (SecureString)
  /myapp/dev/api-key

メリット:
  - 集中管理
  - 暗号化
  - バージョン管理
```

### 4. 構成維持

```yaml
構成:
  State Manager → EC2 → 定期チェック

例:
  - CloudWatch Agentインストール維持
  - セキュリティ設定維持
  - コンプライアンス確認
```
