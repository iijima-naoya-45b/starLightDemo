## AWS Systems Manager とは？


**ポケモンで例えると**: AWSを理解することは、新しい「わざ」を覚えるようなもの——使いこなせば、より強力な開発者になれます。

Systems Managerは、AWSおよびオンプレミスのインフラを統合管理するサービスです。運用タスクを自動化し、可視性を向上させます。

### 主要機能

```yaml
Session Manager:
  - ブラウザベースシェル
  - SSH/RDP不要
  - 監査ログ自動記録

Run Command:
  - リモートコマンド実行
  - 複数インスタンス一括操作
  - CloudWatch Logs統合

Patch Manager:
  - パッチ管理自動化
  - スケジュール適用
  - コンプライアンス

Parameter Store:
  - 設定・シークレット保管
  - 暗号化（KMS）
  - バージョン管理

State Manager:
  - 構成維持
  - 定期的な状態確認

Automation:
  - 運用タスク自動化
  - ワークフロー定義
```

### Session Manager

```yaml
特徴:
  - SSH/RDPポート不要
  - ブラウザアクセス
  - IAM認証
  - CloudWatch Logs記録

メリット:
  - セキュア
  - 監査可能
  - Bastion不要
```

### Parameter Store

```yaml
種類:
  String: 通常文字列
  StringList: カンマ区切り
  SecureString: KMS暗号化

階層:
  /app/dev/db-password
  /app/prod/db-password

無料枠: 10,000パラメータ
```

### 料金

#### 基本機能（無料）

| 機能 | 価格 | 備考 |
|---|---|---|
| **Session Manager** | 無料 | インスタンス接続 |
| **Run Command** | 無料 | コマンド一括実行 |
| **Patch Manager** | 無料 | パッチ管理 |
| **State Manager** | 無料 | 状態管理 |
| **Inventory** | 無料 | リソース情報収集 |

#### Parameter Store料金

| パラメータ種類 | 価格 | 制限 |
|---|---|---|
| **Standard** | 無料 | 最大10,000個、4KB以下 |
| **Advanced** | $0.05 / パラメータ / 月 | 制限なし、8KB以下 |

| 機能 | 価格 | 備考 |

### まとめ

**Systems Managerの重要ポイント:**
- 統合運用管理
- Session Manager（SSH不要）
- Run Command（一括操作）
- Parameter Store（設定管理）
- Patch Manager（パッチ自動化）
