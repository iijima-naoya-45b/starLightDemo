## AWS Config とは？

AWS Configは、AWSリソースの設定を記録・評価・監査するサービスです。

### 主要機能

#### 1. 設定記録

```yaml
概要:
  - リソース設定の継続的記録
  - 変更履歴追跡
  - 関係性マッピング

記録内容:
  - リソース設定
  - メタデータ
  - 関連リソース
  - タグ
  - 変更時刻
```

#### 2. Config Rules

```yaml
概要:
  - コンプライアンスルール
  - 自動評価
  - 継続的監視

ルールタイプ:
  マネージドルール:
    - AWS提供
    - すぐに使える
    - 例: encrypted-volumes
  
  カスタムルール:
    - Lambda関数
    - 独自ロジック
```

#### 3. 対応リソース

```yaml
主要サービス:
  - EC2（インスタンス、SG、VPC）
  - S3（バケット、ポリシー）
  - IAM（ユーザー、ロール、ポリシー）
  - RDS（インスタンス、スナップショット）
  - Lambda（関数、レイヤー）
  
  その他100以上のリソースタイプ
```

### コンプライアンスダッシュボード

```yaml
表示内容:
  - 準拠率
  - 非準拠リソース一覧
  - ルール別評価結果
  - トレンド分析

アラート:
  - EventBridge統合
  - SNS通知
  - 自動修復トリガー
```

### 自動修復

```yaml
概要:
  - 非準拠リソースの自動修正
  - Systems Manager Automation
  - EventBridge連携

例:
  - 暗号化されていないEBS → 暗号化
  - パブリックS3バケット → プライベート化
  - 不要なSGルール → 削除
```

### Config Aggregator

```yaml
概要:
  - 複数アカウント/リージョンの集約
  - 一元表示
  - クロスアカウント監査

用途:
  - 組織全体のコンプライアンス
  - セキュリティ監査
  - レポーティング
```

### 料金

```yaml
設定項目記録:
  - $0.003 / 設定項目 / リージョン

ルール評価:
  - $0.001 / ルール評価
  - $2.00 / Conformance Pack / リージョン / 月

無料枠:
  - なし（従量課金のみ）
```

## まとめ

**Configの重要ポイント:**
- 設定変更の継続的記録
- コンプライアンス自動評価
- 変更履歴追跡
- 自動修復
- マルチアカウント集約
- 監査証跡
