## AWS Config とは？


**ポケモンで例えると**: AWSを理解することは、新しい「わざ」を覚えるようなもの——使いこなせば、より強力な開発者になれます。

AWS Configは、AWSリソースの設定を記録・評価・監査するサービスです。

### 主要機能

#### 1. 設定記録

```yaml
概要:
  - リソース設定の継続的記録
  - 変更履歴追跡
  - 関係性マッピング

記録内容:
  - リソース設定
  - メタデータ
  - 関連リソース
  - タグ
  - 変更時刻
```

#### 2. Config Rules

```yaml
概要:
  - コンプライアンスルール
  - 自動評価
  - 継続的監視

ルール種類:
  マネージドルール:
    - AWS提供
    - すぐに使える
    - 例: encrypted-volumes
  
  カスタムルール:
    - Lambda関数
    - 独自ロジック
```

#### 3. 対応リソース

```yaml
主要サービス:
  - EC2（インスタンス、SG、VPC）
  - S3（バケット、ポリシー）
  - IAM（ユーザー、ロール、ポリシー）
  - RDS（インスタンス、スナップショット）
  - Lambda（関数、レイヤー）
  
  その他100以上のリソース種類
```

### コンプライアンスダッシュボード

```yaml
表示内容:
  - 準拠率
  - 非準拠リソース一覧
  - ルール別評価結果
  - トレンド分析

アラート:
  - EventBridge統合
  - SNS通知
  - 自動修復トリガー
```

### 自動修復

```yaml
概要:
  - 非準拠リソースの自動修正
  - Systems Manager Automation
  - EventBridge連携

例:
  - 暗号化されていないEBS → 暗号化
  - パブリックS3バケット → プライベート化
  - 不要なSGルール → 削除
```

### Config Aggregator

```yaml
概要:
  - 複数アカウント/リージョンの集約
  - 一元表示
  - クロスアカウント監査

用途:
  - 組織全体のコンプライアンス
  - セキュリティ監査
  - レポーティング
```

### 料金

#### 設定記録料金

| 項目 | 価格 | 備考 |
|---|---|---|
| **設定項目記録** | $0.003 / 設定項目 / リージョン | リソース設定変更時 |

#### ルール評価料金

| 項目 | 価格 | 備考 |
|---|---|---|
| **ルール評価** | $0.001 / 評価 | 設定変更時の評価 |
| **Conformance Pack** | $2.00 / Pack / リージョン / 月 | 複数ルールのパック |

**無料枠: なし（従量課金のみ）**

**料金計算例（100リソース、月間1,000設定変更、10ルール）:**

| 項目 | 計算 | 料金 |
|---|---|---|
| 設定項目記録 | 1,000 × $0.003 | $3.00 |
| ルール評価 | 1,000変更 × 10ルール × $0.001 | $10.00 |
| **合計** | - | **$13.00/月** |

**料金計算例（Conformance Pack使用、1,000リソース、5 Pack）:**

| 項目 | 計算 | 料金 |
|---|---|---|
| 設定項目記録 | 1,000 × 10変更/月 × $0.003 | $30.00 |
| Conformance Pack | 5 Pack × $2.00 | $10.00 |
| **合計** | - | **$40.00/月** |

**コスト最適化のポイント:**
- 重要なリソース種類のみ記録
- 不要なルールの無効化
- Conformance Packで複数ルールをまとめて管理
- 開発環境は除外

## まとめ

**Configの重要ポイント:**
- 設定変更の継続的記録
- コンプライアンス自動評価
- 変更履歴追跡
- 自動修復
- マルチアカウント集約
- 監査証跡
