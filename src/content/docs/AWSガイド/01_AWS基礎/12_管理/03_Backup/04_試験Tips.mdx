## SAA（ソリューションアーキテクト アソシエイト）

### 頻出ポイント

#### 1. Backup基本概念

```yaml
出題パターン:
  「複数サービスのバックアップ一元管理」

正解:
  - AWS Backup
  - バックアッププラン
  - タグベース
```

#### 2. クロスリージョン

```yaml
シナリオ:
  「ディザスタリカバリ対策」

正解:
  - クロスリージョンコピー
  - 自動化
  - 定期テスト
```

## SAP（ソリューションアーキテクト プロフェッショナル）

### 高度なシナリオ

```yaml
エンタープライズバックアップ:
  要件:
    - 組織全体管理
    - コンプライアンス
    - 自動化

  設計:
    - AWS Organizations統合
    - バックアップポリシー
    - Vault Lock
    - クロスアカウント
```

## よくある間違い

```yaml
❌ 誤り:
  「Backup でリアルタイムレプリケーション」

✅ 正解:
  - Backupはスナップショット
  - スケジュールベース
  - リアルタイムはレプリケーション機能使用
```
